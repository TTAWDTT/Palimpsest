## 改动

- GitHub 私有仓库改名为 `TTAWDTT/Palimpsest`；Python 分发名称为 `palimpsest`。
- 模拟器迁至 `src/palimpsest/simulation/`，采用安装后的 `src` 布局。
- 抽取分类评分、同源配对、延迟、分位数、CSV、推理清单校验、图像变换和流式文件校验；实验不再从 baseline 分析脚本借用这些实现。
- 独立的投影像素面积数值参照迁至 `simulation/reference.py`，供测试和收敛实验共同使用；它仍独立于优化渲染器。
- 458 处初始 `Path` 表达式改为共享配置，随后补齐动态结果路径及三份 PowerShell 入口。Python 实验不再硬编码本机 C/E 盘根目录。
- 合并重复实现，清理未使用导入并统一 Python 排版。首次清理移除 132 项未使用导入；后续提取也经过静态检查。
- 配置集中到 `configs/`；报告目录由 `outputs/` 改名为 `reports/`。
- 测试按 simulation、data、evaluation、infrastructure 分类，维护检查加入 GitHub Actions。

## 保留的边界

本次没有重新运行 RR 全量 baseline、参数拟合、真实图像模拟或训练。历史结果继续使用原数据、划分、阈值、随机种子和指纹；结构测试通过不代表物理模型已被真实设备验证。

部分数据集专用实验仍在模块顶层读取本机结果，尚未统一成无副作用 CLI。协议相关的频谱窗、归一化、设备拟合和来源划分保留在实验中，没有仅因形式相似就合并。

`origin_simulation` 兼容目录只转发历史模块命令，不保留第二份科学实现；`experiments/paths.py` 保留历史路径导出。新代码使用公共包。

整理前版本：`649c601b6bc15a1e132cbb3c25f63ed4fb342c40`。早期实验若要求更旧的精确代码，应遵照对应报告，而非修改旧指纹。

C 盘任务目录仍被 Codex 持有。迁移收尾脚本已适配有意的代码重构与 Codex 临时 Git refs；默认仅检查原业务文件和本机产物，指定 `-Finalize` 才改目录，保留旧目录备份。
