# 统一评测与数字传播对照

[源码导览](../src/README.md) · [实验入口](../experiments/origin_detection/propagation_controls/rr/README.md) · [研究结论](../reports/README.md)

本轮只开展统一评测与数字传播对照。自研来源算法、模型训练、定位质量评测和拍屏新组件开发暂缓。现有 B-Free 是固定测量工具，不随对照结果调整权重或阈值。

## 处理清单与验收

- [x] 检索原有全量 CSV、报告、清单、冻结来源和模拟物化索引。
- [x] 提取公共缓存评测：直接读取原 CSV，校验有限分数/耗时、错误、标签、唯一性和独立清单覆盖。
- [x] 为固定阈值边界、缺失、重复、错误标签/文件名、非有限分数、文件指纹和配对误差方向写针对性验证。
- [x] 新入口复用三种 baseline 的逐图结果；指标须与历史汇总逐项一致。
- [x] 冻结 1,000 开发来源与两项对照，验证原图/传播图/当前模拟图 SHA，以及校准 donor 角色。
- [x] 物化新对照；对不涉及裁剪的 674 个来源，配对消融与当前模拟逐字节一致。
- [x] 只推理新对照图，各 1,000 张；官方 B-Free 权重、单图、五块、tile64、TF32 关闭，预热20张。
- [x] 统一汇总分类、同源变化、分数变化误差、失败复现与五特征分布；据配对区间判断当前复杂度是否有收益。
- [x] 报告结论、限定可推断范围；代码与报告进入同一审阅分支。

结果见[本轮报告](../reports/02_数据与基线/RR统一评测与数字传播对照_2026-10-05.md)。普通固定 resize/JPEG 的 B-Free 分数误差更低，裁剪消融未显示明确改善；不据此调参或宣布物理模拟完成。

## 固定对照

参数见 [rr_propagation.toml](../configs/evaluation/rr_propagation.toml)。对照在新推理和分数比较之前确定，没有搜索最佳质量或分辨率。

| 条件 | 输入与处理 | 要检验的因素 |
|---|---|---|
| original | 发布包原图，复用历史分数 | 检测器参照 |
| released_transfer | 作者发布的真实平台传播配对图，复用历史分数 | 内部真实处理对照；缺逐图操作日志 |
| current_simulation | 已冻结的校准类别配平、全池独立几何/JPEG donor 版本 | 当前统计模拟 |
| fixed_resize_jpeg | 原图 Lanczos 等比缩小到长边最多1024，禁止放大，JPEG Q40、4:2:0 | 单一普通数字处理基线 |
| matched_resize_jpeg | 沿用当前模拟的输出尺寸和校准 JPEG donor，统一直接 resize | 只去掉当前模拟中的中心裁剪分支 |

固定 Q40/1024 对照利用了已有领域认识，并非未经观察 RR 的盲设定。配对消融保留相同量化表与采样，避免把编码改变误认为几何收益。所有模拟参数选择均不读取目标类别或目标传播像素；标签用于已有 donor 池配平与分层评价。目标传播图只用于评价。

尺寸/质量的单一配置不是完整的最佳简单模拟搜索，不能因胜过它就宣布优于所有 resize/JPEG 方法。

## 数据角色和方向约定

使用已冻结 registry 的 `development` 1,000 来源，AI/自然摄影各500。donor 只能来自 `calibration`。`reserved_simulation_check` 不参与物化、拟合、评价或调参。该划分形成于 RR test 内部，不能称为新的独立测试集。

原图、目标传播图和各模拟条件按同一来源对齐。当前来源均没有非平凡 EXIF 方向；若出现，入口拒绝运行，需先明确一致方向协议。粗图像诊断使用128像素方形缩放，仅服务于描述性统计；检测器继续读取各条件的完整编码图片并执行官方预处理。

补充 SHA 角色审计发现：开发集内部无逐字节重复原图，但 `real/real_008903` 和 `real/real_009936` 分属校准/开发且原图 SHA 相同。原冻结划分只保证来源ID不相交，不能写成图像内容完全无重叠。主分析仍保留预先冻结的1,000来源；另排除这一个开发来源做999来源敏感性分析，不根据结果调整主样本或模拟参数。近重复仍未全面审计。

## 评价与判定

1. **硬性准入：**全量 baseline 同步排除14个已知精确重叠组，三条件 16,986/16,986/16,985，指标与原报告逐项一致。传播对照每条件1,000张且来源/标签/文件名/图像SHA覆盖准确。失败或缺失不能作为零分计入。
2. **主比较：**当前模拟相对固定 resize/JPEG、相对配对 resize 消融的分数误差改善。定义为 `|真实分数−对照分数|−|真实分数−当前模拟分数|`，真假类分别平均后再平均，正值表示当前模拟误差较小。按来源配对、类别分层 bootstrap 2,000 次，种子20261005。区间跨零时，不作明确改善结论。
3. **下游诊断：**BA、AUC、真假类正确率、同源 BA 变化、Pearson、原图判对而传播判错的复现召回与精确率。不能仅因模拟 BA 接近真实 BA 就判定模拟合格。
4. **处理诊断：**亮度相关、平均RGB变化、梯度比、宽高比例的 W1 分布距离；分开报告各特征，单位不同不加总。已选特征无法排除未测量的处理差异。
5. **几何消融：**按当前模拟冻结的 resize/crop 分支分别汇总；这些是模拟策略标签，不是作者平台操作标签。
6. **速度：**使用原 CSV 记录的单图 E2E P50/P95，注明硬件、协议和运行来源。不混淆模型加载、渲染速度和检测速度，也不把不同时间/缓存的结果作严格速度竞赛。

本轮不训练二样本 RF 诊断器、不根据检测器分数拟合 simulation、不重跑已有 RR 全量推理。对照若没有收益，应缩减假设或保留失败结论；不能立即扩大调参直到结果改善。

### 本轮执行故障与恢复

`matched_resize_jpeg` 首次推理完成223张后出现 CUDA `unknown error`，子进程与调度进程均退出。没有证据确定驱动故障的具体原因。独立 CUDA 运算与同步检查随后通过。恢复前核对原运行的 CSV/summary 指纹、权重、vendor、实际判别代码、清单和1,000张对照图SHA；成功前缀的来源/文件名/标签与有限分数/耗时也通过核验。显式 `--resume` 保留223张成功前缀，只运行剩余图片；失败行不进入评价。完整故障摘要和旧运行签名保留在新运行的 `resume_audit` 中。

恢复代码只修改调度入口，未改变模型、判别实现、输入或推理协议。完成项复用以判别实现与输入签名为准；调度入口的新旧SHA均可在运行记录中追踪。
