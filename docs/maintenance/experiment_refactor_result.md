整理基线为 `21a4b1e`。研究保持暂停；本轮没有下载研究数据、重跑 baseline、拟合真实数据或训练模型。

## 审查与处理

| 发现 | 处理 |
|---|---|
| 205 个非初始化模块按数据集、动作和物理路径混合命名 | 五个领域入口，问题与数据范围分层；文件按执行角色命名 |
| 17 个模块在顶层打开研究文件或写结果 | 移入显式 `main()`；比较 baseline 的排除来源由调用传入 |
| 另一个数值实验在导入时渲染，D3 在导入时改搜索路径并加载第三方模型 | 渲染移到入口；第三方模型显式延迟加载 |
| 前轮路径替换导致 14 个文件中的 17 处方法绑定到字符串 | 修正括号，加入静态规则与实际写文件回归 |
| 通用读取藏在实验入口，其他脚本反向依赖它 | HTTP Range/ZIP、视频、Raw2Event、CIFAR、RR 配对及图像指标进入公共库 |
| 准备、光度、频谱和几何步骤被多个入口借用 | 八个问题协议模块；相同的计算体提取后由入口调用 |
| 部分指纹引用旧源码路径，提取后可能漏记实现依赖 | 更新当前源码位置，并纳入协议及解码依赖；不重签旧缓存 |
| 目录索引没有运行边界和前置条件 | 44 个范围说明、领域/问题导航、入口表及迁移表 |

当前有 212 个非初始化 Python 模块及 7 个 PowerShell 入口。文件数包含新增的共享协议模块；不同历史假设、失败诊断和冻结划分没有机械合并或删除。实验间符号导入从 391 条变为 362 条，仍有专用跨问题依赖，其位置在 README 中列出。

清理了过时的 `experiments/paths.py` 和旧分类目录；上一轮目录索引移入维护记录。三个历史下载器改用共享路径配置，之后运行时日志写入配置的 `work` 目录；原日志与研究产物保留。

本机原始校验记录位于 `E:\ai_image_origin_research\cache\experiment_refactor_artifacts_before.json` 与 `experiment_refactor_verification.json`。云端验证以本轮 PR 当前提交的 Checks 为准；前轮公开后的 main CI 已通过。

## 保留的限制

这是源码结构与运行边界的验证，没有证明历史实验在任意数据/依赖环境下都能重新完成。固定窗口、插值、相位和来源划分保持原协议；尚未实现统一配置接口或实验调度器。物理模拟的真实验证状态没有因整理而提高。
