# 实验目录重构处理清单

基线版本：`21a4b1e0793ee6526ffc41d6448e91a118ad0fd6`。用户已合并前轮重构并公开仓库；本轮先审查，再按本清单处理。研究实验保持暂停。

## 审查结论

- 共 205 个非初始化 Python 模块，存在 391 条实验间符号导入；名称和分组混用数据集、动作、物理路径。
- 17 个模块含顶层文件/图像操作，部分脚本导入时就执行分析或写结果。
- 上轮 `Path(...)` 替换为路径除法时遗漏括号，个别文件操作实际绑定到了字符串；这是运行缺陷，优先修复。
- 公共读取能力仍留在实验入口：远程 ZIP、RAW 视频帧、CIFAR 来源、RR 配对与图像指标。
- 没有发现较长顶层函数体完全相同的副本；相似流程和实验间耦合需要按语义审查，不做盲目去重。
- 校准、来源划分、RAW 尺寸、窗口与插值属于协议，不能因重构改动。

## 命名与目录约定

目录表达“研究什么”，文件表达“执行哪一步”。例如 `screen_capture/raw_geometry/evaluate_phase.py`；数据集由问题内的 `raw2event/` 协议范围或配置明确。使用 `prepare`、`audit`、`run`、`fit`、`evaluate`、`plot`、`benchmark`；需要限定词时说明对象或对照，不用泛称 `probe`。

没有统一配置接口的历史脚本不伪装成可任意切换参数的统一入口。本轮可以先形成命名与协议边界，不能为减少文件数把 12 个来源和 100 个来源强行并成一个未验证流程。

归档只针对已确认被替代的内容；失败证据、校准约束和对应报告保留。所有运行输出继续写入原记录位置，不重生成历史指标。
