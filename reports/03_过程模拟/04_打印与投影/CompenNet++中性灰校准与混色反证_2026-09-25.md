# CompenNet++ 中性灰校准：亮混色改善，暗混色反证

2026-09-25。接续[原生画幅几何与 13 色响应实验](CompenNet++原生画幅几何光度联合前向实验_2026-09-25.md)。**结论：**用五档中性灰为已有 13 色响应增加一个全局输出色调映射，20 张纹理留出图的平均 RGB MAE 从 **0.06280** 降到 **0.05799**，但仅 **14/20** 张改善；一个低亮混色留出色块反而退化。中性灰能解释部分残差，却不能证明相机存在可单独标定的固定色调曲线。

## 固定设计与数据

保持上一实验的同一组 `light1/pos1/cloud_np`、42 对结构光、源图在投影画幅中的位置变换、**37,839** 个相机内容像素、13 张纯色通道阶梯，以及全部 20 张未用于参数拟合的纹理图不变。新取得中性灰输入 `ref/0032`（64/255）和 `ref/0094`（191/255）各自的投影源图和相机图，**4 个新增 ZIP 成员**逐一核对中央目录 CRC、长度与本地 SHA。加上前一轮的 80 个成员，本实验使用的 **84 个成员**均有逐成员校验；官方 11.48 GB 全 ZIP 仍未整体验收。

黑、64、128、191、255 五档灰图编号为 **1、32、63、94、125**。先对每档用原 13 色模型预测相机 RGB，再和真实灰图形成五对输出响应。我们在相机有效内容区内，对每个输出通道取这五对响应的**空间中位数**，建立全局分段线性、单调的码值映射。另设一个每个相机像素各自建五档映射的高容量对照。两者都只使用灰图，**不**使用混色编号 31、95、训练图 3 或测试纹理图调整参数。先前看过的测试 1–3 仍使整个实验是探索性的。

这个后映射是在已编码的相机 RGB 上拟合的**复合有效响应**。灰图的投影机通道、布幕、相机曝光与 ISP 混在一起，不能把拟合曲线直接命名为相机 gamma。

| 同一 20 张纹理，MAE 越低越好 | 平均 MAE | 比原 13 色模型改善的图数 |
|---|---:|---:|
| 原 13 色分通道曲线相加 | 0.06280 | — |
| 加全局五档灰输出映射 | **0.05799** | **14/20** |
| 加逐相机像素五档灰输出映射 | 0.05801 | 13/20 |

逐像素映射拥有远多于全局映射的自由度，却没有提高这 20 张图的平均值。基于当前样本，不能把更多空间参数等同于更真实的过程。

## 两张未参与校准的混色反证

| 留出纯色块 | 原 13 色 MAE | 全局灰映射 MAE | 逐像素灰映射 MAE |
|---|---:|---:|---:|
| `ref/0031`：低亮青色 | **0.00594** | 0.00933 | 0.00861 |
| `ref/0095`：亮红加中高绿/蓝 | 0.03865 | **0.01599** | 0.02052 |

灰映射修正了亮混色的部分饱和/响应误差，却破坏了原本已很准的低亮青色。五档灰从投影输入到相机输出，不能给所有颜色提供同一物理解释。额外的 sRGB 逆变换假设在上一实验中也只对 11/20 张纹理有效，并将中灰留出误差从 0.07103 增至 0.14019；这些对照要求后续模型显式检验**输入通道交互与亮度条件**。

## 对后续模拟的约束

可继续研究受限的非线性通道交互，并在未参与参数选择的混色块与纹理图上双重验证；优先比较同一参数在另一个布幕或光照设置上的迁移。**不要**把这次 0.05799 的数值外推到真实拍屏、RRDataset 再数字化或 AI/自然来源检测。它只是在一组真实投影—相机配对上的有效 RGB 前向误差。

复算程序为 `experiments/projection_capture/raw_response/compennetpp/evaluate_neutral_tone.py`，逐图与混色留出结果在 `work/compennetpp_neutral_tone_probe.json`；新增成员审计在 `work/compennetpp_raw_neutral_ramp_probe.json`。文件均位于 E 盘既有 `compennetpp_raw_ref_probe` 目录，复算命令：

```powershell
uv run python -m experiments.data_preparation.compennetpp.run_raw_reference_pairs --ref-numbers 32 94 --test-numbers --output-json work/compennetpp_raw_neutral_ramp_probe.json
uv run python -m experiments.projection_capture.raw_response.compennetpp.evaluate_neutral_tone
```
