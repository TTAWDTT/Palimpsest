## 先理解这条逻辑

**物理假设 → 可运行前向模型 → 数值核验 → 真实过程验证 → 来源判别验证。**

目前数值核验已有较多结果，真实过程验证只有局部证据，来源判别验证仍显示明显失配。测试通过、渲染提速和局部误差降低，不能替代后两步。

## 当前最关键的缺口

- **任务效果不符：**Chimera 同源实验中，真实拍屏使自然图的 B-Free 分数上移，模拟却下移。仅拟合颜色、模糊或总体频谱不足以解决。
- **参数无法唯一辨认：**Raw2Event 中不同屏幕格距/模糊组合可以有几乎相同的 RAW 平均误差。[具体证据](02_拍屏实测/Raw2Event虚拟屏幕格距与光学模糊不可辨识性_2026-09-25.md)。
- **设备变化仍不能充分预测：**ImageNet-ES 的有效响应在低 ISO 跨内容留出上有效，在高 ISO 上失配。[具体证据](02_拍屏实测/ImageNetES跨内容留出反证_ISO响应不能共用单一色调律_2026-09-25.md)。
- **外部比较不足：**尚未在统一真实配对协议下完成与代表性 simulation 方法的系统对照。
