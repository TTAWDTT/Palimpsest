相比旧双特征 M（合计 764/1155、`66.15%`、BA `67.42%`、宏 AUC `0.7482`、AI 检出率 `54.65%`），升级后的四特征白化 M 多判对 **67 张图像**（+5.80 个百分点），AI 检出率提升 **+14.01 个百分点**，且在全部 5 个视图条件上的固定零阈值准确率与 BA 均超过 B-Free。合计类别宏 AUC 在每个内容类别内池化五视图后计算，再对三个类别等权平均（`cat` 0.8439、`church` 0.7052、`horse` 0.8326），不是表中五行 AUC 的平均。

## 与 B-Free 的配对证据

按类别×标签分层做 2000 次来源级 bootstrap（seed=20261011），抽取来源时携带五视图和两方法。总体 M−B-Free 准确率差为 **+9.35 个百分点**（95% 区间 **+3.55 至 +14.89**）；BA 差 **+7.89 个百分点**（95% 区间 **+2.22 至 +13.31**）；类别宏 AUC 差 **+0.0811**（95% 区间 **+0.0149 至 +0.1447**）。三项核心指标的 95% 来源级配对置信区间均显著大于零。

B-Free 在纯净原图上的无阈值类别宏 AUC（0.9109）仍高于 M（0.8400），但因固定零阈值失配及屏摄退化，M 在全部五种视图下的固定零阈值准确率均高于 B-Free。上述是既有开发数据上的比较，尚未打开历史封存的 231 个 test 来源；公开分数可重新计算全部点指标及总体配对区间。

B-Free 分数来自本地先前已完成的 1155 张官方模型推理，本发布不再运行该模型。代码 revision `c6a9f898782fb466b29af01f21960b67415afb0e`，模型 `BFREE_dino2reg4`，权重 SHA-256 `5948ca78f4d94e820c250d24cdf155035b4a85960443800bfe6bb7f06bffe947`。官方预处理使用原尺寸 RGB、官方归一化、patch 对齐五裁切及特征图周期复制；FP32，TF32 关闭，`logit>0` 判 AI。参考[官方代码](https://github.com/grip-unina/B-Free/tree/c6a9f898782fb466b29af01f21960b67415afb0e/code)和[Palimpsest 既有尺寸报告](../02_数据与基线/Chimera真实拍屏_B-Free外部配对Baseline_2026-09-25.md)。

## 数据与来源

原始 1200 个来源划分为 calibration 738、development 231、历史 test 231，同一来源各处理视图共享角色。M 参数只来自 calibration 原图；M 推荐使用已反复探索的 development 结果。此发布只重跑 development 像素，没有打开历史 test 像素，没有重新选择公式、参数或阈值。

Mac 普通屏摄来自 MacBook/iPhone；显示器普通屏摄来自 LG/Blackfly。`attack_mac` 和 `attack_monitor` 为数据集的对抗再采集，独立于普通屏摄。实际微信发送/转发/下载不在这里的五条件中。

来源 ID 是本地冻结清单中的来源分组键，标签单列；每条记录的 SHA-256 标识对应输入文件。CSV 不包含图片、生成提示、设备私有信息、本机绝对路径或模型权重。相对路径是本地数据整理映射，复算图片需自行依法获取和映射数据；分数复算无需图片。

## 发布溯源

新核心从旧 `intermittency_relation_candidate.py` 和 `ess_trajectory_candidate.py` 中提取前两轴，去除关系与置乱计算。旧完整核 SHA-256 为 `8aa30800b919d61a047a1b632aaf5731c060df97f036de7f1bc81c3a314a265a`，ESS 核为 `fb25468927fbdb0f9e949c3831f85792edfa4ed39518f74c3e32555af34dfc1b`；旧四轴标定文件 SHA-256 为 `21d7b2bffc962d847618e983a4e50c1d5c0f6504d546725ebd9f6ba39369e603`。新参数文件只收录 M 两轴，参数数值保持一致，文件哈希自然不同。

全量打包回归使用仓库锁定 Python/NumPy/SciPy/Pillow 环境，逐图验证 SHA、两轴、M、判别与边际 QC。实际版本、最大误差、新代码和工件哈希见 [packaging_regression.json](packaging_regression.json)。这是实现一致性验证，不能把重复推理写成新的独立测试。M-only QC 只检查两轴可计算性，不再包含旧关系轴的退化检查；全部强制分数保留在评估分母。

公开 `evaluation/metrics.json` 由新评估器从 CSV 重算。重采样区间使用相同来源层、固定 seed=20261011、2000 次抽样；新实现的随机抽样流与旧评估器不同，所以区间末位可以不同，点指标应完全一致。
