# 受控响应判别能否保持传播稳定性

## 阅读得到的边界

[RA-Det v1](https://arxiv.org/abs/2603.01544)学习扰动生成器并融合语义、差异、残差分支；不是纯传统算法。其传播测试是较轻 JPEG 与高斯模糊，不是物理再拍。文中模糊两端 ACC 为82.93%和78.73%，相差4.20pp；作者成绩不能代替本项目同源复算。代码默认配置与论文训练参数不同，执行前应绑定具体版本。

[2026中间表示论文](https://arxiv.org/abs/2605.04358)用带标签数据搜索层号和扰动强度，再以响应相似度判别。附录选择的层随探针变化：模糊用13，JPEG与若干噪声用24。冻结权重不等于没有数据选择，也不能从探针判别 AUC 推出先经过真实传播后决定仍不变。

已读页、图表、代码片段及未执行部分见[来源账本](../../sources/2026-10-06_response_mechanism_review.json)。RA-Det 发布代码固定到`591d4c0d24798b49dc881af58093883c6fdf45f9`，47份文本逐一核对Git blob。只读指定路径，没有运行作者完整模型或训练。

## 单图部署核查

README 的大 batch 建议涉及训练统计，不能直接认定推理依赖同批其他图片。已读推理代码计算逐图 L2 与差分，再执行冻结归一化分支；评价明确使用最大分支概率融合。后续若复现，必须实际检查 batch1 与置乱批次，不能根据 README 自行推断失败或成功。

RA-Det 的训练还有学习探针与损失归一化，不能把其性能全部归因于某个固定余弦距离。本项目当前暂停最终神经训练，可先检验固定探针加传统头，但必须注明是适配实验。

## 精确反例：方向敏感度不是正间隔保证

为判断我们能否依赖作者严格正间隔引理，先登记目标与拒绝条件，再用两个不同执行路径核查：有理多项式运算和 SymPy 符号积分。后一条路径没有读前一条脚本。两者共享原文与待核反例，不是独立检测数据证据。

令输入空间为二维平面，真实图的抽象流形为横轴，编码器

\[
f(x,y)=(x,2y),\qquad J_f=\operatorname{diag}(1,2).
\]

切向敏感度平方为1，法向为4，严格满足原文所述方向敏感度次序；但

\[
G=\lVert J_f\rVert_F^2=5
\]

处处恒定。真实分布取横轴上均匀分布，训练锚点取横轴两端，锚点附近取任意正半径的等权高斯混合。因此两种分布下的期望都为5，差值严格为0。伪造差值1被两条执行路径拒绝。

这说明：**印刷版方向敏感度条件不足以推出严格正间隔。** 附录还使用了 `G` 的法向／切向 Hessian 曲率排序；那是更强条件，本反例不满足它。没有因此否定额外条件下的 KL 比较，也没有推导作者实际检测器必然失败。

核查等级保留 PROVISIONAL；没有完成 `prove-protocol` 全部多路线与接口闭合流程，不使用 VERIFIED-CLOSED。本仓库有[无模型精确重放脚本](../../experiments/origin_detection/response_probe/audit_theory.py)，可写到指定的新输出文件；原始两路脚本、运行版本与错误植入证据保存在忽略的工作区。

## 对算法迭代的影响

一个判别探针可能区分原图，却在图像先经历模糊、重压缩或屏摄后失去真假差异。新路线必须把这些作为输入条件，逐类检查绝对判别、同源下降与速度。不会把低响应、低分数漂移或批均值改善单独当作成功。

第二十四轮先检验固定第12块表示，保持原模型末端特征逐值一致。随后可检验同一固定表示对受控探针的响应是否提供额外证据，避免事后搜索层号。只有开发证据支持后，才将固定方法绑定外部未曝光队列；RR reserved继续封存。总体研发目标仍未完成。
