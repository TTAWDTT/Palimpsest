# 从生成机制寻找可解释判别量

[从生成环节推导可观测差异](从生成环节推导可观测差异_2026-10-11.md)按上采样、反向去噪分布与潜空间解码展开假设、代数预测和反例，并明确单图估计与传播验证的缺口。它是当前机制研究入口，没有新分类成绩。

同日第6节追加：7组有限总体矩控制、逐项损坏双胞胎，以及官方LDM上采样类的手写核执行。结果区分“一个量消失”与“所有二阶关系无相位差异”，并核周期假设与实际零填充边界的不同；没有训练权重或完整生成器证据。

第7节追加滤波／平移／噪声响应：总体跨频率协方差与归一化相干的性质分开，包含能消除耦合但保留非零能量的低通反例。接续研究有限样本估计误差。

第8–9节：精确有限窗口分布展示无总体耦合时的非零估计与相关窗口的误差；官方ft-MSE权重校验后完成三个受训上采样子层的48项系数检查。下一步为完整解码链与真实隐藏输入，尚未进入来源分类。

[第1–9节的独立审阅](referee_sim_生成过程差异推导.md)包含独立精确复算、九类受众两轴及证据层级审查。两处记录范围问题已修正；它不预先认证后续解码链实验。

第10节最新：4张历史fit原图和完整AE链的相关隐藏输入预测、最近邻→bilinear单环节干预、普通缩放对照。像素统计变化方向不统一；固定相位CV不作为AI判据推进。没有分类性能或真实传播验证。

第11节最新：共享输入系数推导的四阶循环关系，在一个低通控制中保留二阶已消失的结构；同时明确独立Gaussian总体性质、信号依赖噪声反例、有限估计方差、DC与相位分组的影响。没有来源特异性、单图稳定性或新BA证据。

[第10–11节的追加独立审阅](referee_sim_生成过程差异推导.md)用集合划分与U-statistic路线复得有限估计方差，核完整DC分布和收据表；两处范围表述已修正。审阅未重跑AE，没有独立真实数据。

第12节补读StyleGAN3，要求候选面对主动抑制混叠的架构，并区分特征不变性与来源可辨性；没有StyleGAN3推理或新的分类结果。[开发计划第33节](../../../docs/robust_ai_detection_plan.md)据此整理接续顺序。
