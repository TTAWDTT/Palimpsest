# 局部统计规则原型

## 做什么

对 uint8 RGB 像素计算局部归一化、跨尺度和通道关系的17项空间统计；由明确的中位数/MAD、方向、截断和等权规则产生AI分数。参数通过有标签的标定得到。它是待验证候选，不是 BRISQUE 复现，也不提供通用AI检测保证。

## 何时使用

用于研究真实传播与再数字化之后，这些信号是否还可区分AI与自然摄影。具体RR划分和标定留在[实验协议](../../../../../experiments/origin_detection/robust_statistics/rr/README.md)，数据路径不进入公共实现。外部模型参考位于相邻`baselines`。

## 输出含义

`StatisticsRule`保存特征索引、归一化量、方向、全局阈值与拟合清单指纹；`LocalStatisticsDetector`实现现有`OriginDetector`协议。分数较大表示更偏AI，严格大于阈值判AI，**不是概率**。空特征规则输出恒零，代表未找到合格特征，不能当作成功检测器。无默认标定参数。

统计量先按去重小块取中位数，再标准化和聚合。文件解码使用共用`predict_file`；其计时不包含输入完整性哈希。`predict`仅接受数组，不读取路径、设备标签或原图。

## 相信输出前要检查什么

已知常量/条纹控制、非法输入拒绝、排序正反与零分控制、保存/加载和完整文件推理见[控制测试](../../../../../tests/detection/test_local_statistics.py)。这些证明实现行为，科学有效性需看真实条件逐项结果与未参与开发的来源验证。速度也需在声明的硬件、线程与尺寸档位实际测量。

## 2026-10-05：配对方向投影扩展

新增`projection.py`，复用本目录的17维特征，拟合处理差分子空间并投影类别均值差。用于检验“能否分离处理方向与来源方向”，不替代首轮已失败颜色规则的历史记录。

`ProjectionRule`保存median/MAD、截断界、单位线性权重及已删除正交基；`PairedProjectionDetector`接受最终RGB图像，输出统计分数和计时。需要有标签及同源真实处理对进行标定，部署时不要求原图。权重为零表示信号被删除，**不是有效稳健检测器**；投影只在截断后特征空间成立。

相信实现行为前先运行独立轴、重合轴、恒零、参数损坏和配对错位控制，详见[第二轮注册及入口](../../../../../experiments/origin_detection/paired_projection/rr/README.md)。科学效果与速度需要另行实测。首轮特征和旧参数schema保持不变，没有为新构造另写提取器。
