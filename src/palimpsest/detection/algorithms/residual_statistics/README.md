# 归一化残差与顺序统计

第六轮开发原型，输入未知处理的uint8 RGB图，输出AI分数；尚未经真实验证。长边限制256、不放大，极小图reflect101补到20；最大像素尺度改变后，不能把它与第三轮512表示混称同一算子。

28维灰度顺序频率复用已有gray_features。RGB每通道按原尺度、1/2、1/4三个尺度计算水平／竖直二阶差分；用7×7局部平均绝对残差加一个8位代码值归一化，量化`clip(rint(2R/(mean_abs+1)),-2,2)`。沿对应轴取连续三个残差，合并顺序反转及全体符号反转的39轨道，水平竖直计数相加后归一化。共351维残差频率，组合379维。

残差压低局部线性内容，局部归一化减少幅度支配；不保证JPEG、非线性色彩、缩放、任意模糊或拍屏不变。固定+1底噪使正增益也不是严格不变。符号／顺序对称来自设计，可能丢弃有用信息。统计思想受SRM启发，不是其完整实现或新颖性声明。

显式ForestRule参数必需；portable森林仅NumPy推理，无默认训练权重。返回分数与阈值，概率未经独立校准，不提供处理条件推断。软件已知答案控制需先通过；真实准确度、重编码及含解码速度另验。
