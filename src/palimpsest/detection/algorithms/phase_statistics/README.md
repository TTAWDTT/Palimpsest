# 闭合相位统计候选

`features.py`提供三个频带的相位矩与有效比例；`detector.py`提供同一标定下的线性/多原型决策和显式参数保存。用来检验有限对称模糊不变性及未知条件下的判别，没有默认训练参数，不声称新颖或真实拍屏稳健。

算法只使用6个偶数次相位矩；有效频率支持比例和奇数矩不参与决策。小于128像素的图会补边。分数越高越偏AI，严格大于阈值判AI；不是概率。参数需来源标签标定。

接受前必须通过人工谐波、支撑不变的循环卷积、反例、CSV筛选和损坏输入控制，随后检验真实处理后的绝对准确率与CPU单图速度。所有边界、候选数和数据角色见[实验登记](../../../../../experiments/origin_detection/phase_statistics/README.md)。
