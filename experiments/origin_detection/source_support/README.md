Register before fitting/indexing or inspecting selection scores. Global linear
source risks and condition gates leave local errors. Test a different decision
geometry: proximity to class supports containing real propagation views of
each FIT source. This is a conventional neighbor method on frozen neural
features, not an original claim of NBNN, a neural-backbone training run, or a
guarantee for unseen devices.

Fixed k=5 distinct sources per class. Two real-label indexes:

five closest DISTINCT sources/class. Difference dREAL-dFAKE is the score.

Distance to a fixed set is 1-Lipschitz. The mean of k nearest source distances
is also 1-Lipschitz; their class difference is at most2-Lipschitz in this
fixed metric. A classification margin greater than twice actual feature motion
is a sufficient local stability condition, not a bound on unseen physical
feature motion. Do not infer retained AI information from smoothness alone.
