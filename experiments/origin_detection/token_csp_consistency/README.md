# 第57轮事前协议：类别相关性方向与来源一致性

第56轮组合均值头仍为86.11%／5pp，固定投影协方差没有改善稳定性。
本轮检验已有CSP原理：在32维协方差空间里，学习真假均值方差对比最强的
16个方向，配合旧2048维中心／RMS。它是传统监督滤波适配，不训练神经
编码器或1024→32投影，不是新的CSP或拍屏不变性原理。

## 事前固定的计算

使用签发第56轮15120×3600缓存，输入选择中心／RMS2048＋root-svec528，
共2576维。从root恢复协方差；固定shrinkage=0.05，使其正定，零root用I/32。
类别均值按来源／域权重估计；解C_fake v = lambda(C_real+C_fake)v，选择
|lambda−0.5|最大的16个方向，稳定排序、欧式单位列及符号规范化。
输出这16个投影方差的log比例（除以16个方差之和）＋原2048维，共2064维。
这与作者原始EEG输入、LDA及未归一化log功率不同，不称复现。

每个CV训练折重新估计类别协方差、方向和分类尺度，禁止全fit先算CSP
再验证held折。五折、seed20261007，1260来源各六weak视图不跨折；真实标签
只用于折分层，null监督滤波使用伪标签。固定强度0／0.1／1／10，源码风险
温度0.1、ridge0.01、尺度下限0.001、LBFGS2000、梯度门控1e−5。

复用30个OOF指标／35配对的80%优先选择器，不按selection调整方向数、
shrinkage或强度网格。真实／null两套40个CV拟合，随后四最终头：zero、
selected、错一致性来源、source-null。错组只改方差惩罚，分类来源及CSP标签
仍是真实的；null的CSP与头全部用伪标签，外层threshold仍用真实标签。

24组真实标签threshold弱视图，selection5040记录／60指标／130配对每头。
单条／批量、portable保存加载及映射后头逐值相同，zero是新的监督映射
基线，不应要求与第56轮线性头相同。所有样本仍是反复曝光开发数据。

## 先行检查与预算

人工同旧对角但相反相关性、训练CSP及头能区分，恒定协方差／零分支、
无效标签／被破坏root拒绝，单条／加载／映射阈值一致；复用来源CV和
方差梯度控制。封存前lint。实际6048×2576、强度10的fold0预算小试，
不计算held或外层分数。若不收敛或超过120秒，先修数值路线；40倍代理
仅估相同折规模拟合，依赖强度及迭代，加载、四最终拟合和评分另计。

绑定新旧源码和缓存指纹，不重跑图像或旧五头。最终整数／OOF、错误分数
／折／BA、emitall及错误报价，全报告raw null区间。仍须80%／2pp及独立
真实验证。均值功率对比可能受离群点和设备影响，token不假定独立或Gaussian；
EEG论文的性能、混合模型及滤波性质不能作为AI／真实传播证据。
