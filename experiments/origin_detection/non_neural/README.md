# 非神经判别研发

主分支合并PR #7后，从 `main` 建立 `ttawdtt/non-neural-detection`。CuRe方法仍保留在模型路线，不删除、不作为本路线成绩。

当前纯算法起点是第15轮：固定像素预处理、灰度顺序／RGB残差／小波包络／RGB联合关系，共850维手工特征，再拟合传统统计判别头。它不调用神经网络，但读出和阈值依然使用带标签数据拟合。

[第73轮特征失效诊断](feature_drift/README.md)只读取原fit角色的已签名手工特征，检查真实处理及JPEG90如何改变类间差异与同源描述符。不使用threshold／selection选择特征，不开启RR reserved或独立验证像素。本轮是下一候选的机制诊断，没有新分类成绩。
