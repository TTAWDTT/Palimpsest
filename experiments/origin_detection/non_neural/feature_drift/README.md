## 问题与范围

对六个固定块分别核对：顺序28、残差351、小波120、RGB偏序135、RGB平局27、RGB联合残差189。只使用历史fit1260来源（RR540、Chimera720），三原生条件×raw／JPEG90六视图，共7560行。原来的420threshold和420selection及其Q70均不进入本轮统计。历史开发来源不是独立验证数据。

每域两项原图→真实处理的raw配对，以及三项同条件raw→JPEG90配对，共10个域／处理对照×六块。以每域原图raw的逐坐标总体标准差归一化（固定floor1e-3），统计类间质心差RMS、同源变化RMS、平均变化RMS和类间差方向余弦。所有坐标参与，常量坐标不删除；非法或非有限值拒绝。

这只是描述符诊断。质心距离不能等同AUC或BA；质心差小仍可能有非线性判别信息，分数／特征漂移小也不能证明准确率稳定。不得以这张表选择参数后再称旧selection独立。下一候选须另登记。
