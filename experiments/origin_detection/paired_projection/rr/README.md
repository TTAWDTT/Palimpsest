# 用配对变化去除处理方向

[算法研发流程](../../../../docs/robust_ai_detection_plan.md) · [首轮特征协议](../../robust_statistics/rr/README.md) · [公共实现](../../../../src/palimpsest/detection/algorithms/local_statistics/README.md)

## 2026-10-05：第二轮注册

注册发生在本轮拟合与结果计算前。前提是首轮颜色规则已经在Chimera失败：原图也偏弱，拍屏进一步恶化。不能把这一失败简单归因于某一ISP操作，也不能在Chimera重新调阈值或翻转方向。

**唯一新假设：**现有17个统计量中，处理造成的主要变化方向与来源类别差异有可分离成分；用fit来源的真实配对差分估计这些方向，再投影类别均值差。若差异与处理方向重合，投影会同时删除信号，这就是需要允许发生的反例。线性投影是常规构造，不提出新颖性或物理不变性主张。

### 数据接触与固定构造

- 完整复用首轮900来源的fit540、selection180、threshold180及原有指纹校验；它们已经暴露，**不是新独立验证**。不读取RR reserved图像、不调整旧registry；不重提取RR图像特征，不重跑已有baseline。
- 只用原有长边512、17维特征。fit三个条件等权合并，逐维median/MAD，MAD下限1e-8，然后clip至±5。在这个截断后的特征空间估计差分；不对原始像素声称严格不变。
- fit配对差分为平台传播减原图、混合再数字化减原图，两块竖直堆叠。**不中心化差分**，以保留共同平移。SVD取前1或3个右奇异方向；另有rank0不投影的均值差参考。共两个候选和一个参考，不搜索新尺度、特征或正则化参数。
- 三条件合并的AI均值减自然均值得到类别方向。去掉它在处理子空间上的投影，L2归一化成为线性权重。均值差被完全删除或没有有效方向时，输出恒零失败规则，不能改回别的权重。
- 参数依赖标签标定，属于显式线性统计规则，**不是完全无需学习**。推理只需最终图像；原图/条件标签仅用于fit。
- 使用原有threshold角色与相同严格大于语义，最大化两个处理条件较差BA。所有三个版本都按此相同规则标阈值。

### 筛选及停止条件

候选须同时满足：非零权重；selection两个处理条件AUC的来源分层bootstrap95%下界>0.5；较差AUC比rank0和旧颜色规则各至少高0.02；两个处理条件的自然和AI正确率均≥0.55。通过后按较差AUC、较小rank择一。门槛用于有限开发筛选，不能作确证或多重检验校正。

若无候选通过，不运行新的Chimera推理、不打开RR留出、不优化这套规则的速度。保留失败原因与处理变化能量/类别信号去除比例。若通过，才规划冻结规则的Chimera诊断和新CPU测量；历史Chimera已暴露，仍不能称盲测。

### 先运行的控制

1. CSV读入→覆盖审计→配对对齐→拟合→阈值→分类：构造独立的类别轴与处理轴，rank1应恢复两处理条件AUC=1；rank0保留处理偏移。
2. 类别轴与处理轴重合时，rank1删除类别差异，应回到恒零/AUC=0.5。全零表也必须准确返回恒零，不能产生SVD任意方向假信号。
3. 差分平移不中心化；行标签/来源错位、重复和非有限数须拒绝；干净孪生通过。参数坏维度、非正尺度、非正交基拒绝。
4. 保存/加载权重与像素推理一致，旧特征实现保持不变。线性投影只验证声明的有限维行为，不证明图像来源分类有效。
