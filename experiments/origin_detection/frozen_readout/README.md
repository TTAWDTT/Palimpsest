# 第五轮诊断：冻结表示的非线性读出

2026-10-05，真实分类器拟合前登记。此轮用于区分决策局限与表示局限，不是新算法或新颖性声明。既有图片和第三／四轮表示不变，不解码图像，不使用RR保留集，不训练神经模型。

## 做什么、何时使用

检验两个固定表示：第三轮28维灰度顺序统计、第四轮同样6维偶相位矩。每个拟合一个固定随机森林：128树、深度6、叶至少8样本、sqrt特征、无bootstrap、单线程、seed20261005。不扫参数、不拼接表示、看过selection后不重标阈值。

八个已使用的处理fit视图等权训练，2520图，标签沿用来源角色；原图不拟合。每视图真假配平，各记录权重为该视图图数的倒数。条件名称只用于训练配平及报告，不进入特征。threshold角色按既有最差视图BA规则标定单一阈值。决策分数为AI概率减0.5；这里的概率没有独立校准保证。

## 输出含义及限制

报告八处理视图及两原图聚合的AUC、真假类正确率、同源配对变化。准确度门槛沿用八视图AUC95%下界严格>0.5、真假类正确率≥0.55、两原图聚合真假类正确率≥0.55。没有通过则停止这些固定读出；通过也只是开发候选，需要速度、重编码及独立验证，不称稳健算法。

每表示另拟合一次来源级标签置乱null：同域同场景内fit来源标签排列，两个处理版本保持同一置乱标签；threshold及selection真值不置乱。固定seed，无重复试种子。它是泄漏／关联诊断，不是多重检验校正或独立泛化证据。null通过门槛即停止解释真实性能并查污染。

人工XOR控制发现单次置乱可偶然保留四模式的类别方向，null也通过；程序正确标记`interpretation_refused=true`。保留该失败警报控制，没有更换seed。真实null若通过须查原因，也可能是偶然关联，不能径直认定数据泄漏。特征全零控制则要求AUC精确0.5。

计时：在真实缓存仅运行ordinal完整fit＋threshold、不评selection，实测1.0515秒。四次拟合按同设置线性计约4.21秒，bootstrap另计、耗时未知；来源规模与历史评测相同，不是长任务。正式进度单位为四个候选／null结果，输出`diagnostic.json`。

已有RR和Chimera接触历史不可抹去；反复利用selection仍是开发，非盲测。分类器失败只说明这些固定设置未检出信号，不能证明表示中没有任何类别信息。输出在`work/robust_statistics/frozen_readout`，本地joblib不进入Git，也不加载外部不可信joblib。

## 信任前的控制与复用

先在独立构造的XOR源表上走CSV→来源身份审计→fit／threshold→selection→JSON／本地保存加载全流程，要求两个类正确率和AUC均为1；把类别关系破坏或所有特征归零应使AUC精确0.5并拒绝门槛。来源标签、角色交换、NaN、重复／缺行、维度不符要拒绝，干净双胞胎通过。改变selection内容不能改变拟合参数或阈值。

`python -m experiments.origin_detection.frozen_readout.run_diagnostic --pilot`仅测完整fit＋threshold，不看selection；记录实测后再开始四个固定拟合。读取父缓存先核验代码、清单、文件指纹，输出目录拒绝覆盖。

已检索BootLoops索引：emitall负责报告数字核验，符号积分／精确代数工具不适合此分类诊断；现有sklearn随机森林负责学习，复用项目来源缓存、feature_views、AUC、配对bootstrap与choose_threshold，仅新增实验编排，不新增公共算法或兼容转发层。
