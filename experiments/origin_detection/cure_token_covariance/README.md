# 第56轮事前协议：冻结token的投影协方差

第55轮非线性读出仍下降3.75pp，最低汇总BA82.22%，低于第54轮。
解析特征袋表明：相同中心、对角RMS仍可有相反的坐标间相关性。
本轮检验这部分信息。二阶池化是已有原理，不是新的不变性定理或作者模型复现。

## 表示和边界

一次不变的CuRe冻结前向，逐值保留第52轮3072维描述符。第二个只读
`ln_post` hook读取同样576×1024个FP32 token。固定Gaussian QR正交投影
1024×32，seed=20261008，按各列最大绝对元素的符号固定列方向，记录矩阵SHA。
先减一个实际token、投影，再去均值，计算总体32×32协方差。

除以trace，计算PSD矩阵平方根；上三角svec的非对角项乘sqrt(2)，输出528维。
零trace输出零；归一化特征值小于−1e−10拒绝，较小负舍入误差裁为零；
非零输出范数须与1相差不超过1e−10。总描述符3600维。这不是径向截断
协方差、Tensor Sketch或iSQRT迭代。

仅声明特征袋的重排、共同偏移、正全局缩放性质。图像几何处理不自动
变成token重排；固定投影丢失方向，注意力使token相关，设备也可能制造
相关性。不训练神经网络或投影，不打开新数据集或RR reserved。
原生6300图、15120视图、1260／420／420来源角色不变；fit用raw／Q90，
selection用raw／Q90／Q70／Q60。

## 先行检查及成本

三个CPU检查涵盖同旧描述符但已知不同相关性、常量／秩亏与有限特征
变换、改变父前缀／概率的拒错。封存代码前先过lint。CUDA检查用三张
人工图验证重复逐值一致和禁用hook后的作者原均值／概率一致。
再使用第52轮已曝光的60图／240视图，核所有3072维父前缀和概率，
并重复60个raw描述符。绑定父数组、元数据、收据、代码与作者权重。

小试特征调用中位预算175ms，仅为工程门控，不是手机速度或用户验收。
按末60调用估算15120次主调用；排除初始化、hash、JPEG物化和重复控件。
超过数小时须先重构计算路线，通过小试才提取完整缓存。

## 固定分类比较

流式保存FP64描述符，不保存全token。完成SHA、维度、有限值、身份、
视图覆盖及范数审计后，才拟合以下五头：

- covariance/source：528维。
- mixed/source、mixed/mean：旧中心＋RMS＋协方差，共2576维。
- full/source：3600维。
- mixed/source_null：2576维，来源配平伪标签。

source温度0.1，mean温度0，ridge=0.01，尺度下限0.001，LBFGS上限500，
梯度要求1e−5。沿用24组threshold真实标签视图，null也一样；null只替换
fit标签、映射不变。不得看结果后扫描强度、种子或投影数。
每头60指标／130配对，报告raw null区间；整数／BA扰动及emitall错误报价
控制齐备。仍须BA≥80%、跌幅≤2pp及独立真实验证，整体系统包含深度编码器。
