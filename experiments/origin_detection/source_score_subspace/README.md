# 第58轮事前协议：少量判别分数方向

第54、55、57轮的最坏处理对不完全相同，但均未达到2pp。
检验把读出限制在三个监督判别方向，而不是再扩充数千维坐标。
这是已有分类器组合／监督低维投影思路，不称新的核、stacking原理或
Super Learner复现，不给出物理不变性保证。

输入仍是第56轮2576维中心／RMS＋root-svec，单一冻结编码器，无新像素。
每个训练折重新拟合三个固定基：中心／RMS的mean风险头（温度0），
同一输入的source温度0.1＋方差强度0.1头，CSP16方向的source温度0.1／
无方差头。ridge0.01、尺度下限0.001、LBFGS2000、梯度1e−5。
不得加载旧全fit规则来做CV，以免基方向包含held来源。

三个基在其训练行上给出三维分数，再拟合source风险＋方差头，固定
0／0.1／1／10网格及第50轮fit-only选择器。基和末级头共享训练行／标签，
不生成OOF元训练分数，可能过拟合；外层五折必须验证整条流程。
两个目标各五折×四强度，共40末级CV拟合。null的全部基、CSP及末级头
都用伪标签，true标签仅做fold分层和最终threshold。错来源只改末级
方差分组，原分类来源／基学习标签不变。

基与末级强度无关。按x／y／weight／source数组形状、显式dtype和SHA
缓存完全相同的训练基，跨标签／折不复用。十个CV基组＋两个全fit基组，
每组3个基；预期12组、36基拟合，不是每末级强度再拟合同样的基。
原来源数不变：1260fit／420threshold／420selection，7560／2520／5040记录。
每组threshold24views，最终四头每头60指标／130配对。

人工控制：已知相反相关性的分类、不同末级强度只复用相同训练基、
翻转标签必须重建基、portable保存加载／单条批量／阈值映射；复用来源CV
及梯度控制。lint先于封存。预算小试实际6048×2576折：先强度10冷建3基，
再强度1暖复用；估10冷建＋30暖末级的40CV代理，依赖强度／迭代，
输入加载、四个全fit头与评分另计。超过数小时须先重构。

最终四控制：zero、selected、错末级来源、source-null。保留全部OOF和
基输入SHA／拟合诊断，重算整数／Fraction、错分数／折／BA、emitall及
错误报价，报告所有raw null区间。80%／2pp及独立真实验证仍必须实现，
不因完成一轮、算术通过或同源分数更接近而终止。
