ensemble result. Single split71 activated the rate penalty but yielded81.11%

a component's final readout the sources used to learn its own basis.

For the same supplied fit context, train A-basis/B-readout and B-basis/A-readout
using exactly71's deterministic partition/supplied labels. Each inner component
uses378 basis/378 head sources, final630/630; each component has5 directions,
20 polynomial terms, same source/rate loss/ftol0 and1e-5 gradient gate. All

whole is not source independent of its training data. Data and labels across
components are dependent. This is conventional sample splitting plus equal
score averaging, not a new optimization theorem, bagging-independence proof,
or Cotter's two-player stochastic classifier.

Prediction is fixed `.5*f_A(x)+.5*f_B(x)` on raw member logits. Members have
zero thresholds; only the whole mean gets the paired BA/drop calibration.

no robustness is inherited. No selecting weights or model subset after outer
inspection. Both components receive the same3920 numeric vector; one frozen
image encoder/feature extraction is reused, with extra numeric readout cost
to be measured later. No claim of image-end-to-end speed from fit times.
