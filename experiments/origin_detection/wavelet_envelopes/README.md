# 二阶小波包络：第十一轮

问题：局部残差的来源线索容易随编码损失，像素门控仍不足。
测试不同范围的空间调制是否提供补充线索。灵感来自 Bruna–Mallat 的小波模值级联；
本离散统计原型不是原论文完整散射，不能直接引用其平滑形变定理保证 JPEG／拍屏。

固定处理：长边≤128、RGB转灰、短边不足32反射补边；局部周期FFT边界；
减均值并除RMS+1；3个中心频率×4方向的零DC Morlet频率核，峰值归一化。
一阶模值mean/RMS共24维。包络面积缩小2倍，再用更粗小波，按父包络mean+1e-3归一，二阶96维。
四组：一阶、二阶、全部120维、旧残差379＋新120维。
各组均用域配平的raw/JPEG90 fit、λ=0且ridge=0.1线性读出，24视图类别阈值。
Q70仅评价；第八轮旧残差λ=0结果作为冻结参照。源标签置乱仅在hybrid执行。
