# 第三轮：跨数据开发的灰度顺序统计

登记日期：2026-10-05。下面规则在提取本轮特征与筛选前冻结。

## 问题与边界

前两轮颜色残差和配对线性投影不能迁移到 Chimera 真实拍屏。这轮检验一个不同的廉价信号：邻域灰度顺序。它受 Ojala 等的 LBP 思想启发，是自定义四邻域轨道统计，不是其论文复现，更不是新颖性结论。

算子：RGB 先按旧有 AREA 长边512函数缩小，不放大；整数灰度 `77R+150G+29B` 不再量化。半径1/2/4/8，四个轴向邻居，reflect101边界。以 `neighbor >= center` 编码16种模式，按旋转90度及反射的等价轨道折叠为6个频率，加邻居相等比例，共28特征。全图统计，不搜索块数、裁剪或半径。

严格递增灰度变换在灰度算子输入上保留大小关系和相等关系；这不适用于变换RGB后再缩放、重新量化、一般角度旋转或真实拍屏。结构不变性不代表 AI 判别力。

## 数据接触与角色

- RR沿用首轮900来源的 fit540、selection180、threshold180及其全部三版本；校验旧审计签名和清单。reserved不解码、不调参。
- Chimera全部已参与先前诊断，现在永久登记为开发数据，不称独立测试。按scene×class对完整来源组做稳定哈希排序，60%/20%/余数分配 fit/selection/threshold，同源三个版本不分开。
- 从公开已审计文件SHA建立来源连通组；跨类别冲突拒绝，跨scene重复组排除，同scene重复保留字典序代表。与RR全清单或RR train/val任一文件SHA相交的Chimera来源组件排除。只是文件精确重复控制，非完整近重复审计。
- 每个Chimera scene×class至少30个可用完整组，否则停止。
- selection仅为本轮开发筛选；历史结果已经影响设计，重新分角色不能恢复盲测资格。

## 仅两个候选

方向统一由RR fit原图特征AUC决定（≥0.5取正，否则负）。

1. original_agreement：保留在RR原图和Chimera三个scene原图上，同方向AUC均≥0.55的特征。
2. processed_agreement：保留在RR传播/再数字化与Chimera三个scene×两拍屏设备，共8视图上，同方向AUC均≥0.55的特征。

分数为保留频率的有符号等权平均；不拟合MAD、权重或交互项。空集合精确零分。全局阈值仅用threshold角色，最大化上述8处理视图中最差BA；平手优先绝对值更小，再数值更小。运行时不提供真实处理类型。

selection门槛：非空，8处理视图来源分层bootstrap2000次的AUC 95%下界都>0.5，且每视图真假类正确率都≥0.55。两个候选若都通过，选择最差视图AUC更高者，平手优先original_agreement。未通过则停止这套构造，不增加候选、软化门槛或动用RR保留集。

无论通过与否，报告两候选、各特征方向矩阵及全部scene/条件，不只展示最好一列。不与已知输出反复调参。通过只意味着值得用未接触数据验证，不能称解决目标。

## 已知答案与失败控制（先于真实特征运行）

1. 常数图：每半径4亮轨道频率=1，相等比例=1，其余=0；构造非恒定图必须能破坏该答案。
2. 单调变换和90度/镜像：独立逐像素Python参照遍历与向量化算子一致；递增立方变换保留，合并灰度阶必须破坏至少一项。
3. 构造两域多视图的JSON/CSV全路径植物：有已知共同特征时仅保留该信号、方向与分类正确；单视图翻转应剔除；零矩阵精确零，门槛拒绝。
4. 同源错配、重复记录、NaN、换标签、文件SHA变化必须拒绝；干净双胞胎通过。序列化在控制阶段验证，包括布尔值与有限数值。

速度只测单图CPU，沿用60个RR文件、3次随机置乱重复，与提取缓存分数逐图校验；含解码/预处理P95预算50ms，核心10ms。预先SHA读盘导致热缓存，模型加载/首次启动不含其中；不把本轮重复旧图推理称新测试。

## 入口

`python -m experiments.origin_detection.ordinal_statistics.run_iteration --prepare`审计并提取开发缓存；`--pilot 60`仅做吞吐试运行，单独文件；无参数从签名缓存筛选两规则。输出`work/robust_statistics/joint_ordinal_statistics/`。`--benchmark`测冻结两规则的速度，不重新拟合。

使用BootLoops planted-truth、independence-bookkeeping、tool-stewardship与emitall；数学引擎不用于这项图像计算。控制成功是软件/算子证据，不是科学目标达成。
