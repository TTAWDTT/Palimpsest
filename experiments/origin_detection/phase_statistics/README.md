# 第四轮：闭合相位与多条件原型

2026-10-05，真实特征提取前登记。沿用第三轮已经审计的2100来源、6300图与全部来源角色；RR保留集不解码，Chimera仍为开发。历史结果已经影响设计，不宣称独立验证。

## 假设及有限不变性

三轮规则失败后，检验一个不同的信号：低/中频之间的闭合相位。定义`C(k)=U(k)^2 conj(U(2k))`，其中`U=F/|F|`。平移造成的相位项消去；对实值频率响应的中心对称循环卷积，`C²`消去频率响应正负号，前提是参与的系数非零且支撑集未改变。

这属于已知phase-only bispectrum路线的适配，不是新颖性声明。[Ojansivu原始论文集/学位论文](https://oulurepo.oulu.fi/handle/10024/35209)提供先行依据。原始有限图裁块、非循环边界、量化、噪声、重新采样及非对称PSF不受这个性质保证；模糊不变性也不保证AI类别有差异。

## 固定算子

- 复用AREA限制长边512、不放大；灰度权重0.299/0.587/0.114。
- 最多4个去重角块，128×128；较小图reflect101补到128。块均值移除，无窗口。
- FFT整数径向带[2,6)、[6,12)、[12,24)，避开DC与加倍后混叠；每带统计`Re(mean C)`、`Re(mean C²)`、`Re(mean C⁴)`及有效频率比例，12特征。
- 有效条件是`|F(k)|, |F(2k)| > 1e-8 max|F|`，有效集随模糊/噪声可变化；没有有效系数时四值都为零。实际图像取块间逐特征中位数。
- 决策只用每带偶数次相位矩共6维，奇数矩与有效比例仅为诊断；不把零幅值当作有相位。

## 两候选、同一标定

仅使用fit来源的8处理视图（RR传播/再数字化、Chimera三个scene×两拍屏设备）。各视图等权：中心为各视图特征中位数的平均，尺度为各视图MAD的平均、下限1e-8，z截到±5。各视图各类别一个均值原型，8×2个；不搜索类内聚类数。

1. linear：8视图AI−natural原型差的平均，归一化后点积；范数≤1e-12返回零。
2. nearest_prototype：到最近自然原型的平均平方距离减去到最近AI原型的距离。真假类可各自匹配不同原型；匹配不是设备识别，也不认证处理路径。

两者均用threshold角色标定一个全局阈值，最大化8处理视图最差BA；平手优先绝对值小，再数值小。运行时只提供像素和固定参数，不提供设备、条件、域、类别或文件元数据。原型与标签标定属于学习，不称完全无学习算法。

selection门槛：8处理视图来源分层bootstrap2000次AUC的95%下界全部>0.5、真假类正确率全部≥0.55；RR与Chimera各自原图聚合真假类正确率≥0.55。另在统一缩放后JPEG90/4:4:4重编码的selection数据上，四个处理聚合条件BA≥0.55，且比原版同条件BA下降≤5个百分点。两者通过时选最差处理视图AUC更高者，平手优先linear。

JPEG对照不消除原有编码残留，不足以证明无编码捷径。没有候选通过时停止这套构造，不增加窗口、频带、原型数、阈值或参与调参的数据。

## 先运行的控制

- 人工指定6对谐波幅度与相位，独立逆合成产生128灰度图，回收每带已知cos2θ/cos4θ；单项相位破坏应改变答案。
- 循环平移、正增益/偏置、实值正/负频响的对称循环卷积保留偶矩（支撑不变），奇矩在符号变化下可变；非对称核、噪声/频率清零作为失败/边界控制。
- 常数图精确零；小图/NaN/无效输入，独立有效比例检查。
- 构造8视图类别方向相反但域偏移可辨的CSV植物：统一线性规则失败，多原型规则恢复已知类别；两个候选都走真实筛选入口、阈值、JSON及保存加载。
- 缓存重行、缺行、同源标签/角色交换、NaN、实际文件字节/SHA/尺寸修改要拒绝，干净双胞胎通过。比较器必须能拒绝故意改错的报告图数。

软件控制先于真实计算，不能将其称为真实泛化证据。

## 运行和产物

`python -m experiments.origin_detection.phase_statistics.run_iteration --prepare`首次提取raw及统一JPEG90两版本；`--pilot 60`独立小计时输出；无参数从签名缓存拟合两个规则；`--benchmark`沿用首轮60文件×3次、CPU/OpenCV单线程，不再拟合。

输出`work/robust_statistics/joint_phase_statistics/`。推理预算为核心P95≤10ms、含解码P95≤50ms，≤2MP单列，同时不隐藏大图档位。准确度未过时不继续优化该构造。原始baseline分数使用第三轮同来源签名缓存，不重跑神经/Benford推理。

复用已签名来源清单、缩放、分类/配对/来源bootstrap和文件解码接口；新公共特征表/文件计时工具须在evaluation登记与控制。BootLoops控制、接触账本和emitall保留；不会修改其安装源码。
