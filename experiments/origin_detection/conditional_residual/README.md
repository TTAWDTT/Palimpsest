# 条件残差判别：第十轮开发试验

第九轮冻结分数在各个条件内有可行阈值，但共享阈值区间不相交。
本轮检验像素统计能否提供额外编码状态的线索，进而允许条件偏置／斜率变化。
它是有学习步骤的传统统计算法；不是纯规则、BRISQUE 复现或未知信道不变性证明。

流程：签名缓存 → fit 来源三折交叉拟合 JPEG90 门控 → `[x,g*x,g]` →
配对岭读出 λ=0/1 → threshold 来源上 24 视图类别最小正确率标定 → selection 评价。
JPEG70 仅评价；没有新增读取 RR reserved。所有既有 selection 都已反复暴露。
门控训练标签只有 extra-JPEG/raw，同源的两种版本权重相同；不使用真假标签拟合门控。
三折按来源哈希划分；图像的全部条件和版本同折。最终推理只收 379 个像素特征。

先运行 `python -m pytest tests/detection/test_conditional_residual.py`。
随后 `python -m experiments.origin_detection.conditional_residual.run_iteration --pilot`，
检查计时再运行无参数主流程。每个结果拒绝覆盖，保存代码与输入指纹。
第八轮 λ=0 是冻结参照；λ=0 源标签置乱是本轮阴性对照。

开发筛选沿用先前 55% 双类／5pp 编码跌幅，仅用于比较。
另报用户目标的暂定 BA≥80%、原图到每个处理及额外编码跌幅≤2pp。
这仍不是最终验收：还须固定方法、独立真实传播／拍摄数据和端到端速度。

风险：extra-JPEG 历史不一定可辨识；门控可能吸收来源信号；三折门控与最终门控存在差异；
编码外推至 Q70、不同真实平台或设备均无保证。两阶段失真推断的动机见 BRISQUE §IV.E，
其两阶段版本也因第一阶段出错而性能降低：不可将该论文当成来源判别保证。
