# 传播后图像原始来源判别研究

研究目标：给定经过平台传播、重存或物理再数字化的图片，判断**原始视觉内容**来自自然摄影还是 AI 生成。最终判别器只接收处理后的图；simulation 研究可以使用数字源图、真实配对、RAW 与设备记录来验证过程。

## 当前状态

- RRDataset 官方测试包已验证并审计；已完成 B-Free、D3 与 Benford 适配版的全量基线。主指标排除 14 个与 RR train/val 逐字节重叠的来源组。见 [三种 baseline 对照](outputs/RRDataset_三种Baseline全量对照_2026-09-24.md)。
- 早期 propagation 和 re-digitization simulation 属于统计原型，尚未证明物理过程正确。见 [过程物理深读](outputs/Simulation过程物理深读_屏摄与印刷成像_2026-09-24.md)。
- 当前阶段先审计真实配对数据并设计受控拍屏测量，随后才实现可证伪的前向模型。见 [数据可用性与采集协议](outputs/Simulation受控采集准备与数据可用性审计_2026-09-24.md)。
