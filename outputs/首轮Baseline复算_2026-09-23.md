# 首轮 baseline 复算：传播后的单图来源判别

日期：2026-09-23。**性质：对论文作者公开的逐图检测器分数进行独立指标复算，不是本机运行模型权重，也尚无端到端时延。** 原图、真实截图和真实拍屏基准仍待取得与审计。

## 输入与计算口径

- 作者原始分数：[QuAD 官方仓库](https://github.com/grip-unina/QuAD) 的 `ReWIND.csv`、`AncesTree_test.csv`、`sources.csv`。分数列为 DMID、CoDE、D3、B-Free、DRCT、CO-SPY；正分判 AI，零及负分判真实。没有重训、调阈值或在测试集上选超参数。[论文](https://arxiv.org/html/2604.15027)
- ReWIND：9,646 个真实网页近重复实例，162 个源图（87 真、75 假），未知具体传播链。除去与 RRDataset 重叠的 1,177 个实例后，还剩 8,469 个实例、139 个源图。
- AncesTree：测试划分有 550 个源图（50 真、500 假），以及 68,200 个 1–5 级数字退化实例。通过 `src` 将 550 个干净原图与五级传播版本配对；每级实例数分别为 2,200、4,400、8,800、17,600、35,200。退化操作包括裁剪、缩放、JPEG/WebP 编码；**没有真实拍屏**。[官方说明](https://github.com/grip-unina/QuAD/tree/main/datasets/AncesTree)
- AUC 按逐图原始分数计算；BA 是以 0 为固定阈值的类别平衡准确率，即 `(真图识别率 + AI 图识别率)/2`。`源图等权 BA` 先算每个源图所有版本的正确率，再分别对真/假源图求均值，避免传播副本多的源图获得更高权重。95% 区间对真/假源图分别有放回重采样 2,000 次，随机种子 20260923；它只反映这批源图的采样不确定性。

## 真实网页传播：ReWIND 单图分数

| 检测器 | 逐图 AUC | 逐图 BA | 源图等权 BA（95% 区间） | 真图识别率 | AI 图识别率 |
|---|---:|---:|---:|---:|---:|
| DMID | 71.7% | 57.8% | 55.9%（54.0–57.9） | 97.7% | 18.0% |
| CoDE | 58.1% | 56.2% | 57.2%（54.0–60.8） | 86.1% | 26.3% |
| D3 | 71.5% | 65.0% | 66.4%（60.8–72.0） | 79.3% | 50.7% |
| B-Free | **92.3%** | **80.4%** | **78.4%（74.1–82.7）** | 98.2% | 62.6% |
| DRCT | 78.7% | 60.0% | 57.8%（54.8–60.9） | 24.4% | 95.7% |
| CO-SPY | 67.7% | 63.0% | 64.4%（59.0–69.7） | 76.6% | 49.4% |

**交叉核验：**上表六个“源图等权 BA”依次为 55.9、57.2、66.4、78.4、57.8、64.4%，与 QuAD 论文表 3 的 `random / 1` 行在四舍五入后逐项一致。原因是每个源图版本正确率的均值，正好等于从该源图均匀随机取一个版本时的期望正确率。表中的“逐图 BA”使用所有实例，因此会受每个源图收集到的版本数量影响；两种口径不能混用。[论文表 3](https://arxiv.org/html/2604.15027)

除去 RRDataset 重叠实例后，B-Free 的逐图 AUC 为 92.2%、BA 为 80.5%；这个数字仅用于重叠敏感性检查，仍包含其他上游数据来源，不等于全新独立测试集。

## 目前能下的结论与缺口

1. 数字传播树已经给出明确的单图基线和可比较的性能下滑。真实网页版本上的固定阈值偏差也很明显：如 B-Free 的真实图识别率 98.2%，AI 图识别率只有 62.6%；DRCT 则朝相反方向偏。后续需在独立验证集校准阈值，并分别报告真图误报与 AI 图漏报。
2. 这批分数由原作者运行模型提供。本轮**没有重新执行模型推理、训练任何模型或测算速度**，也无法从真实网页近重复图还原传播操作顺序。真实屏摄、截图与复合链的鲁棒性仍没有 baseline 数字。
3. ReWIND 只有 162 个源图，且包含 RRDataset、B-Free 等上游图像；AncesTree 只有 50 个真实类测试源图。后续比较必须先锁定源图分组、排除训练和测试重叠，并按源图统计不确定性。多次传播版本不能当成独立照片来扩大有效样本数。

## 传播版本之间的判定不一致（追加分析）

对每个源图，从其可用版本中**随机抽两个不同版本**，计算二者被同一检测器判为不同类别的概率；再对真、假源图分别求均值并平均。这个指标不依赖每个源图采集到的版本数量，也不需要知道哪个版本先传播；但**始终判错**的方法仍可获得 0% 不一致，因此必须与上面的准确率一起看。

| 检测器 | ReWIND 版本两两不一致率 | AncesTree 第五级版本两两不一致率 |
|---|---:|---:|
| DMID | 13.2% | 35.8% |
| CoDE | 21.1% | 25.1% |
| D3 | 15.3% | 13.1% |
| B-Free | 12.9% | 15.8% |
| DRCT | 18.0% | 15.0% |
| CO-SPY | 21.5% | 10.4% |

ReWIND 的版本变换未知，AncesTree 同一级内的兄弟节点有不同随机操作；两列不能解释为“同一强度的真实传播”。该指标使本项目的“判别能力下降极小”更具体：既要维持传播后绝对正确率，也要减少同一源图在不同传播版本中的判定翻转。

4. RRDataset 原始与测试包校验、解包并确认标签/配对以后，在同一模型、同一预处理、同一阈值设置下跑真实平台与真实再数字化；若缺逐图配对字段，就分别报各条件绝对性能，不能伪造同源跌幅。

## 元数据捷径负对照（追加分析）

为检查检测器是否可能仅利用来源文件的粗浅差异，把 ReWIND 的 162 个源图按真/假标签分层分入五折；同一源图的全部传播版本始终在同一折。仅用 CSV 已公开的文件格式、短边尺寸的 `⌊log₂⌋` 分箱，以及二者组合，在训练折估计各类别的条件频率，测试折使用对数似然比与固定零阈值。没有读取图像像素，**它不是可部署的视觉判别算法**。

| 输入元数据 | 逐图 AUC | 固定零阈值源图等权 BA |
|---|---:|---:|
| 格式 | 43.0% | 51.5% |
| 短边尺寸分箱 | 61.6% | 59.0% |
| 格式 + 尺寸分箱 | 62.1% | 59.3% |

这里用逐图实例计数估计条件频率；改为每个源图总权重相等后，三项源图等权 BA 分别为 51.8%、59.0%、59.1%，结论相近。可见尺寸确有弱标签关联，因此后续训练和验证需平衡分辨率与编码来源，且以源图隔离划分。该五折诊断与上文作者公开分数的测试集复算**不是同一训练协议**，数字只能用于排查捷径，不能解释为与 B-Free 公平的性能比较。脚本及完整结果分别为 `work/metadata_shortcut_diagnostic.py` 与 `work/metadata_shortcut_diagnostic.json`。

**本机速度记录：**完成模型加载后，每个续跑批次对前 20 张图预热；计时从图像文件解码/预处理开始，到单张 GPU 同步后判分结束，含 CPU→GPU 传输。按实际运行模式分层：前段未分块 2,159 张端到端 P50/P95 为 **278/364 ms**，其中 GPU 传输与前向 P50/P95 为 261/281 ms；后段分块 3,423 张端到端 **302/360 ms**，GPU 传输与前向 **286/301 ms**。两段处理的图片及尺寸分布不同，**不能把两段延迟差直接解释为分块开销**。混合全体的端到端 P50/P95 为 295/361 ms，只描述此次批处理，不是统一执行模式下的手机端性能。计时脚本和分层 JSON 分别为 `work/run_bfree_baseline.py`、`work/summarize_bfree_latency.py`、`work/bfree_rewind_latency_by_mode.json`；完整分类和来源分层结果为 `work/bfree_rewind_complete_metrics.json`、`work/bfree_rewind_by_dataset.json`。

**证据定位：**这是公开权重在一个真实网络近重复子集上的本机 baseline，解决了“尚无本机评测和速度数据”的缺口。ReWIND 已用于研发诊断，且子集含上游训练来源；它仍**不能证明对全新生成器、未知真实拍屏或复合传播的泛化**。RRDataset 真实传播测试包正在下载，只有完整包的长度与作者 MD5 通过、逐样本处理标签核查后，才进行下一项真实性能测量。[B-Free 官方实现](https://github.com/grip-unina/B-Free)；[QuAD 官方数据](https://github.com/grip-unina/QuAD)
