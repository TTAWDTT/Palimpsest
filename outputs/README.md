# 研究导航｜先看这里

**问题：**只看传播后的图片，判断其原始内容是自然摄影还是 AI 生成。可遇到平台缩放/JPEG、截图、拍屏、打印扫描、拍打印件、拍投影及组合。

## 当前结论（2026-09-24）

1. **基线已跑全量。** RRDataset 排除 14 个与 train/val 逐字节重叠的来源组后，共 50,957 张；三种方法都在真实再数字化条件下明显退化。主要对照见[全量结果](02_数据与基线/RRDataset_三种Baseline全量对照_2026-09-24.md)。
2. **Simulation 仍在验证阶段。** 早期统计原型能靠近部分任务指标，却不能证明拍屏/打印的真实形成过程。依据[物理机理](03_过程模拟/Simulation过程物理深读_屏摄与印刷成像_2026-09-24.md)，现已实现[拍屏空间链前向原型](03_过程模拟/Simulation首个物理前向原型_拍屏空间链_2026-09-24.md)，但尚未取得真实设备校准或外部干预验证。
3. **研发目标尚未完成。** 目前没有经外部真实采集验证的完整过程模拟器，也没有自研的高速稳健判别算法或模型。下一步先检查操作参数改变时，几何、颜色、频谱和条带能否按物理机制联动，再扩大前向模型。
4. **真实拍屏配对已经开始实包验证。** [Dragotti 小规模跨设备审计](03_过程模拟/真实拍屏跨相机配对与过程约束_2026-09-24.md)逐图核验 2 张相邻原拍及 12 个再拍条目；同一相机在相邻原拍上的条件性几何换算稳定，但这批图缺逐张物理设置与 RAW。[其他数据线索](03_过程模拟/真实拍屏受控数据再检索_2026-09-24.md)仍待获取实包，不能视为完整受控参数网格。
