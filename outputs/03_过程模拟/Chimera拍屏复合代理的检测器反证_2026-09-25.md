# Chimera：像素更近，来源判别却不像真实拍屏

2026-09-25。**结论：**在外部真实拍屏数据上，冻结的“发布图几何＋复合 RGB＋有效 Gaussian 模糊”代理能降低未见内容的像素误差，却没有复现固定 B-Free 检测器在真实拍屏上的主要退化。它是一次**对当前模拟假设的反证**，不是已完成的物理 simulation。

## 数据、冻结方式与因果范围

[Chimera 官方数据](https://zenodo.org/records/14736478)的原图及 MacBook→iPhone、LG→Blackfly 两套普通拍屏图已经整包哈希、逐图解码和同源审计；详见[数据与过程审计](Chimera真实拍屏配对实包审计_2026-09-25.md)。这里只看预先冻结的 **240 校准、120 开发、840 保留**来源划分：几何、颜色和有效模糊均只在校准来源拟合或选档；在这次实验里，**保留来源既未参与调参，也未生成模拟图**。开发集每种场景×真假有 20 来源，共 120 来源；它是模拟器开发验证，不能替代[1,200 来源的外部真实拍屏基线](../02_数据与基线/Chimera真实拍屏_B-Free外部配对Baseline_2026-09-25.md)。

为了消除发布分辨率差异这一明显混杂，比较中的真实拍屏图和模拟图都为 **256×256 PNG**；真实图来自对发布拍屏图的固定 Lanczos 缩小。待评模拟代理按以下顺序作用于同一 256×256 原图：

`原图 → 每设备固定复合 RGB 映射 → σ=0.7 输出像素的 Gaussian 低通 → 每设备固定发布图仿射放置 → 8 位 PNG`。

仿射只描述作者裁切/我们缩小后的输出空间；RGB 是已编码值上的 3×3＋偏置；Gaussian 在已编码 RGB 上作用。**这条链没有真实显示面板发光、镜头 PSF、CFA/RAW、曝光噪声或 ISP 参数**。这些环节不能从最终 PNG 中单独辨识。代理生成时没有读取开发来源的真实拍屏像素。B-Free 使用同一官方权重、单图协议与固定 `score > 0` 判 AI 阈值，不为代理或真实图重新校准。

## 逐来源检测器结果

下表每设备都使用完全相同的 **120 个开发来源**；“原图”在两设备下为同一组。BA 是固定零阈值的平衡准确率；AUC 衡量分数排序。

| 输入 | AUC | BA |
|---|---:|---:|
| 数字原图 | 0.8558 | 75.00% |
| Mac 真实拍屏，缩至 256 | 0.7642 | 64.17% |
| Mac 复合代理图，256 | **0.8708** | **77.50%** |
| Monitor 真实拍屏，缩至 256 | 0.7358 | 60.83% |
| Monitor 复合代理图，256 | **0.8775** | **75.00%** |

相对于同来源真实图，代理把 Mac 的 BA **高估 13.33 个百分点**（按场景×真假六层逐来源 bootstrap，95% 区间 **+6.67 至 +20.02**），Monitor **高估 14.17 点**（**+8.33 至 +20.83**）。AUC 也分别高估 **0.1067**（区间 +0.0380 至 +0.1761）和 **0.1417**（+0.0722 至 +0.2142）。真实 Mac/Monitor 拍屏分别使原本判对的 **16/19** 来源变错，代理分别只复现其中 **3/3** 个；代理分数变化与真实分数变化的逐来源 Pearson 仅 **0.378/0.498**。

真实拍屏相对原图的平均分数变化在 Mac/Monitor 都约 **−0.21**，代理却为 **+0.64/+0.28**。真实与代理分数的 MAE 为 **1.712/1.638**；直接假设“拍屏后分数不变”的 MAE 为 **1.650/1.837**。也就是说，Mac 代理按这一任务指标甚至比不做模拟更差，Monitor 只略有改善。不能用此前较低的像素 MAE 宣称保留了原始来源判别证据。

## 对下一轮物理 simulation 的约束

在同一 120 开发来源上，固定几何与复合颜色已把 Mac/Monitor 发布图空间的 RGB MAE 降至 **0.06280/0.04911**，再加校准选出的低通降到 **0.05751/0.04415**。但检测器结果方向仍不对。这说明**所用 MAE、全局色调与平均模糊不足以约束判别器所依赖的变化**；它不自动证明剩余差异必然来自某个特定莫尔纹或 CFA 模式。候选原因包括局部几何、空间变化的光学 MTF、屏幕子像素与相机采样的混叠、设备 ISP/去噪/锐化、噪声结构、裁切和颜色非线性。

下一步应优先在**校准/开发来源**上追踪输出残差的局部频谱、边缘扩散与平坦区噪声，逐项给前向模型加可测条件和消融。必须保留简单缩放/模糊/颜色代理作为负对照；新组件需同时改善真实图过程观测量和固定检测器的**同源分数变化与错误翻转**，才有理由进入 840 保留来源的一次性检验。Chimera 缺逐图距离、角度、对焦、RAW，因此即使通过该留出，也仅支持其发布设备域，不能证明真实物理参数已被识别。

### 首轮残差频谱探针及其失败边界

只在同一 120 开发来源/设备上，把真实 256 图按固定几何对齐到原图坐标，减去冻结代理的对齐输出；在原图低梯度四分位像素上测残差高通 RMS，并从每图最平坦的 64×64 块取二维频谱峰。Mac/Monitor 的平坦区高通 RMS 中位为 **0.00651/0.00543**；与逐来源 `|真实 B-Free 分数−代理分数|` 的 Spearman 仅 **−0.188/−0.075**。简单峰值/中位功率比中位虽为 **220/117**，但峰常落在所选频带的低频边界约 0.1 周期/输出像素及坐标轴附近，与分数误差的 Spearman 仅 **+0.091/−0.047**。这些峰很容易由背景缓变、裁切/配准残差或内容边缘造成，**不能标为屏幕格点或莫尔纹**。多个探索性指标和 256 缩小使这种相关分析尤其不适合做因果结论。

机器记录 `work/chimera_residual_spectrum_development.json`，复算 `uv run python -m work.probe_chimera_residual_spectrum`。下一轮频谱研究应先在未缩小的真实拍屏图、已知显示校准图案和阴性对照上确定空间频率与白化方法，再检验它是否解释同源分数迁移；这套自然/AI 来源图只有结果观测，不能反向充当屏幕子像素地面真值。
