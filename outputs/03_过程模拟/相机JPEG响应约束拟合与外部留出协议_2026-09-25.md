# 拍屏 JPEG 响应：固定一条可证伪的光圈／ISO 转换律

2026-09-25

## 固定的开发实验

使用[已核验的 ImageNet-ES 二十个同源开发组](ImageNetES_ISO与光圈联合干预及读出增益模型_2026-09-25.md)。本实验不反求相机 RAW：仅把 f/5、ISO 250、1/60 秒的**发布 JPEG**作为输入，预测同源其他相机设置的发布 JPEG 编码亮度分布。跨条件可能有细小配准差异，所以先用每张图的亮度直方图与 10%–90% 分位数检验。

预先选定一条低维的**有效发布图响应假设**：

`y_out = clip[(y_base + toe) × ((5/f)² × ISO/250)^gamma − toe, 0, 1]`。

这里 `y` 是发布 JPEG 的编码亮度；`gamma`、`toe` 在所有来源和条件之间共享。`(5/f)²`只表示理想瞳孔面积比，`ISO/250`只表示**名义读出增益比**。这不是传感器响应定律，也不能从 `gamma`、`toe` 辨认真实 T-stop、黑电平或相机 ISP。

**只用**开发二十组的 `param_4→param_13`，即 f/5→f/9、ISO 250，按 17 个亮度分位数拟合两个参数；`param_5/14/22/23` 不参与拟合。拟合后固定 `gamma=0.5694751717`、`toe=0.0950458149`。代码 `work/fit_imagenet_es_effective_tone.py`，逐来源结果 `work/imagenet_es_effective_tone_dev.json`。

| 目标条件 | 是否用于拟合 | 二十来源的编码亮度均值 MAE 中位 | 预测/真实亮度均值比中位 | 分位数 MAE 中位 |
|---|---|---:|---:|---:|
| f/9，ISO 250 | 是 | 0.0084 | 0.964 | 0.0191 |
| f/16，ISO 250 | 否 | 0.0090 | 1.000 | 0.0130 |
| f/5，ISO 2000 | 否 | 0.0649 | 1.085 | 0.0601 |
| f/9，ISO 2000 | 否 | 0.0766 | 1.143 | 0.0819 |
| f/16，ISO 2000 | 否 | 0.0499 | 1.125 | 0.0562 |

低 ISO 的 f/16 条件虽未参与拟合，亮度均值预测接近，但两者仍在同一批**开发内容**上；不能把它当独立外部成功。高 ISO 三档均系统偏亮，说明一个跨 ISO 共享的幂律加暗部截断不足以解释成片；可能涉及模拟/数字增益拆分、ISO 相关降噪/色调、高光压缩、实际镜头与灯光误差。当前数据不足以归因。

## 冻结后的独立内容检查

下一次只按作者 test split 类别 ID 的 SHA-256 固定排序，取排名 **21–40** 的二十个新类别，每类取同样哈希规则下的一个新来源；不得根据画面或预测结果挑选。只下载同一六条件和数字参考，逐图验 CRC/SHA。用上面已经写定的两个参数预测，**不再拟合或重选公式**，并将新来源与开发结果并列报告。该检查验证的是换内容后的有效 JPEG 响应，不验证真实传感器参数或 OLED 子像素/几何全过程。
