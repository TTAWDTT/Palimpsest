# 拍屏模拟路线再定位：从莫尔纹合成到可证伪前向链

2026-09-25。本文核查已有模拟路线，决定本项目下一步要验证什么。**研究对象是拍摄后图像中原有内容的来源判别**；“图中有没有莫尔纹”只是传播过程的一个可变观测量。用户暂时无法提供手机实拍，以下继续使用公开原始论文、代码和已核对的真实配对数据。文中“物理前向”表示操作的因果顺序与可测参数相符，**不表示当前代码已完成真实手机拍屏标定**。

## 一、已有方法具体模拟了什么

| 方法 | 生成机制 | 主要验证 | 对本项目的作用和边界 |
|---|---|---|---|
| [LCDMoiré，Yuan 等，2019](https://arxiv.org/pdf/1911.02498) | 把 LCD 像素写为 3×3 的 `[K,K,K; R,G,B; R,G,B]`，随机角点透视、3×3 高斯模糊、Bayer 采样与高斯噪声、双线性去马赛克、OpenCV 降噪，随后 JPEG、对齐和裁剪。论文发布 10,200 对**合成**图。 | 去莫尔纹挑战的还原指标；作者明确承认单一 LCD 布局、单一 CFA，且特定真实相机可能有合成域差距。 | 可作为“简化成像链”对照，不能把其合成图当真实采集。固定 3×3 子像素和固定模糊无法表达某显示器填充率、实际光学 MTF 与弱纹/无纹区域。 |
| [Moiré Attack，Niu 等，2021](https://arxiv.org/html/2110.10444)及[官方代码](https://github.com/Dantong88/Moire_Attack) | 缩放→RGB 子像素→随机透视/径向畸变→Bayer→在传感器处加入**经受害模型梯度优化**的扰动→双线性去马赛克/降噪。 | 对受害分类器的攻击成功率、迁移性。 | 其子链与我们同属按顺序成像的尝试，但扰动为攻击目标优化，不能当作无条件真实传感器噪声分布；论文也未以已知相机的留出真实成对图校准整条前向链。 |
| [UniDemoiré，Yang 等，2025](https://arxiv.org/html/2502.06324)及[官方仓库](https://github.com/4DVLab/UniDemoire) | 用手机拍**纯白屏**，汇集 15 万张 4K 莫尔纹图案；扩散模型生成新图案，再与自然图乘法/Grain Merge 混合，并用网络修正色调。 | 去莫尔纹模型跨数据集的 PSNR/SSIM/LPIPS 等。 | 这是有价值的**统计图案合成**，不是给某张输入图执行显示→镜头→传感器的对应前向操作。论文明确按色彩度/清晰度滤掉几乎不可见图案，故不能据其数据覆盖无明显莫尔纹的真实拍屏。仓库同时有数据链接和待发布事项；本次只核论文/仓库，未验下载包。 |
| [Chimera，Park 等，USENIX Security 2025](https://www.usenix.org/system/files/usenixsecurity25-park.pdf) | 对具体相机/屏幕调整对焦等条件，并学习该设备对的再拍变换及其补偿，目标是让伪造内容绕过再拍与深伪检测。 | 多组真实设备上的检测器攻击。 | 与本项目威胁模型直接相邻：**离焦可压低可见屏幕纹理，同时也损失内容锐度**。不能把“莫尔纹弱”当作“非拍屏”或模拟失败。其学习型变换针对设备对与攻击目标，不能自动视作跨设备物理模型。 |

LCDMoiré 五步机制与作者限制来自论文第 2.1 节及结论；Moiré Attack 六步机制和“优化传感器扰动”来自原论文第 3.2–3.3 节；UniDemoiré 的纯白屏采集、筛除弱纹、混合/色调网络来自第 4 节；Chimera 的对焦试验来自第 4.3 节。这些工作的目标分别为去莫尔纹或攻击，不能拿其原论文成绩充当“自然摄影 vs AI 原始内容”的评测。

## 二、可证伪的物理主张

对同一显示图 `X`，拍屏分布应由一组**相互约束**的条件生成：

`X → 显示缩放/色彩响应/子像素发光 → 相对姿态与镜头 PSF → 像素面积积分/CFA/曝光噪声 → ISP → 发布压缩`。

例如，改变拍摄距离同时改变“一个屏幕格落在多少传感器像素”、内容在画幅中的尺寸和可能的曝光；改变光圈同时改变衍射截止和达到同等亮度所需曝光；离焦同时削弱格点与内容高频。把这些量**独立随机叠加**能生成图，却无法检验过程正确性。我们的 [Dragotti 条件性频率预算](Dragotti拍屏格点与衍射截止的条件性预算_2026-09-25.md)给出一个实例：在作者 EOS600D 配对的特定画幅假设下，屏幕基频约 0.753 周期/相机像素；f/11、f/13 的理想衍射预算可压制大部分或全部示意波段格点。它是带前提的机制解释，**不是发布 PNG 的镜头或光圈实测**。

更具体地，设显示平面上的周期波矢为 `k_d`（周期/显示像素），相机图上某点到显示坐标的局部雅可比为 `J = ∂x_d/∂x_c`。在该点附近，投影后的波矢约为 **`k_c = Jᵀ k_d`**；相机像素采样后，观测波矢按二维采样格折回到奈奎斯特区，即 `k_alias = k_c − n`，其中整数向量 `n` 选到各分量落入 `[−0.5, 0.5]`。镜头、离焦、像素面积积分和 CFA/ISP 在折回前后分别改变不同通道的幅度与相位。透视使 `J` 随位置变化，因而同一张图上的可见条纹可能改变方向/间距；只贴一张固定频率的正弦纹理无法满足这一局部频率关系。这是局部线性化的**模型推导**，不是直接测得的设备参数；若光学 MTF 已压低该格点或屏幕发光结构不同，条纹也可能弱到不可见。

我又对当前前向程序作了**内部数值检查**：固定假设的 1.327151 相机像素/屏幕格、64×64 相机画幅，分别显示一张 0.5 灰平面和一张带 0.2 周期/屏幕像素正弦细节的灰图。只改变理想圆孔的 f 数，在 CFA/ISP 之前测屏幕格折叠频率 **0.246506 周期/相机像素**的幅度，以及内容频率 **0.150699** 的幅度。测试没有使用真实照片，也没有拟合任何真实设备参数。

| 理想光圈假设 | 灰平面屏幕格混叠幅度 R/G/B | 内容低频幅度 R/G/B |
|---|---|---|
| 不启用衍射 | 0.06281 / 0.05815 / 0.06513 | 0.05533 / 0.05818 / 0.05936 |
| f/8 | 0.00428 / 0.00893 / 0.01561 | 0.04672 / 0.04822 / 0.05031 |
| f/11 | 0.000017 / 0.000043 / 0.00295 | 0.04226 / 0.04410 / 0.04630 |
| f/13 | 0.000026 / 0.000014 / 0.000039 | 0.03912 / 0.04144 / 0.04400 |

这与理想衍射预算的**方向**一致：f/11 时蓝格点剩约不启用衍射的 4.5%，红绿接近零；f/13 三色都接近零。同时内容细节也变弱，不能通过只删除莫尔纹来代表该干预。极小值间的不严格单调来自有限图像/卷积核及频率拟合数值误差，不解释为物理反弹。程序把 PSF 核归一化，**没有模拟光圈改变时的光子通量、曝光补偿或噪声变化**，因此不能用这张表预报真实手机在 f/8、f/11、f/13 下的照片。复算：`uv run python -m work.check_screen_alias_aperture_sweep`；逐通道数值在 `work/screen_alias_aperture_sweep.json`。

由此把两类输出都列为目标：**强纹/弱纹/无可见纹的拍屏**。只在有明显莫尔纹的图片上拟合，可能让模拟器、快速检测器和模型共同依赖易消失的证据。下游的判别指标还必须按同一原图的真实再拍前后评分变化报告，而不只报告图像的均方误差或“模拟图像是否能骗过域分类器”。

## 三、已有工作对我们模型设计的直接校正

目前 `origin_simulation/screen_capture.py` 是可运行的结构原型：可配置单应几何、矩形竖直 RGB 发光区、面积积分、可选理想圆孔衍射、简化噪声/CFA/ISP、PWM/逐行曝光。**“可配置”不等于“已测得”**。LCDMoiré 的固定黑色第一行与我们的矩形竖直 RGB 都只是显示器假设；Moiré Attack 的可微管线说明前向链不是新概念。当前可能有价值的研究贡献，要落在以下可检验位置，而不是宣称首创整个拍屏仿真：

1. **参数绑定。**把格点尺度、姿态、镜头/采样衰减与输出频谱一起约束，报告模型在真实跨相机条件中的误差；不能只搜索一个让图看起来相似的任意周期纹理。
2. **负样本覆盖。**明确考核无可见纹而仍为真实拍屏的样本，按纹理强度和内容锐度分层报告，不按“有纹”筛选验证集。Dragotti 作者数据偏向压低可见莫尔纹，可作这一路径的部分外部证据，但缺逐张显示帧与曝光元数据。
3. **识别性。**单靠最终 JPEG 很难唯一估计屏幕填充率、光圈、离焦、ISP 锐化。参数先按物理可测量量和范围记录；无法识别的量作为联合不确定性，不能把拟合值命名成设备真值。
4. **独立验证。**现有 CompenNet++ 两个投影设置的 [原生画幅前向对照](CompenNet++第二真实设置与显示放置迁移_2026-09-25.md)已经显示，四个颜色端点会污染几何拟合，而 13 色与结构光可降低该误差。这证明“几何和光度联拟合会互相代偿”的方法学风险，**不能把投影结论直接搬到 LCD 拍屏**。

## 四、下一轮具体实验门槛

按以下顺序推进，每一步都允许被数据否定：

1. **先冻结分层测试。**公开 Dragotti 已核源/再拍对作为“弱纹可能性较高”的屏幕域；另外需找或核实强纹真实配对，不能用 UniDemoiré 纯白屏图案替代来源图配对。只在源图和真实再拍能逐图对应时计算内容保持与检测器分数迁移。真实图不能凭主观观感标成“无纹”，须预注册局部频谱与人工复核程序。
2. **选少数可识别条件校准。**可先测输出的几何、整体色调和有效模糊包络；把“光圈、离焦、运动、ISP 各自贡献”保留未识别，不从一张图反推。旧代码的 f 数分支可做参数敏感性而非设备复现。
3. **物理变化测试。**当公开数据或以后自采数据提供同一内容下的距离/角度/对焦/曝光干预时，固定其它条件，比较**变化方向、幅度与耦合**：格点局部频率、内容边缘 MTF、色块响应、行带相位、检测器分数。若模拟器只能在单张图上逼近 MAE，却不能预测这些干预，前向假设失败。
4. **下游判别测试。**固定 B-Free/D3 等检测器，对真实与模拟的同源分数变化、错误翻转、端到端耗时分开报告，并保留简单 resize+JPEG、LCDMoiré 机制及纹理叠加这几类对照。模型训练必须等外部真实再拍门槛通过后才有强结论。

**目前判断：**项目已有结构代码、公开投影真图的局部验证和拍屏频率的条件预算，但尚无在已知手机/显示器设置下的屏幕子像素、镜头、RAW/ISP 联合标定。此阶段应继续核真实配对数据与物理干预可用性，并把模拟器当可被推翻的假设，而不是已完成的真实拍屏模拟。

实验几何记录的精度不能省略。[Chen 与 Mow 的显示屏—相机通道实测](https://arxiv.org/pdf/1501.02528)用四角参考点校准位置；在其条码通信设置中，仅改变约 **2° 视角与 3 cm 距离**，误码空间分布的一致性指标便明显下降。这是条码通道实验，不是本任务的来源判别效果值；它说明把“近距离拍屏”混成一个无姿态记录的条件，难以用来检验空间频谱预测。

[Liu 等的聚焦/离焦去莫尔纹研究](https://arxiv.org/pdf/2011.02055)提供另一条方法学提醒：其实拍集包括 **50 对屏幕莫尔纹的聚焦/离焦照片**，拍摄时远程控制手机以减少调焦引起的晃动，并用白色背景定位、单应变换配准；但是其**合成**屏幕实验的离焦图则由干净图施加高斯模糊与高斯噪声得到。两者不能混作同一种物理证据。聚焦变化会联动屏幕格点可见度、内容锐度和视场/配准，日后若拿到实拍配对，应同时检查这三项，而不能只按“莫尔纹减少”判断仿真成功。当前只核对了论文方法，没有核验其真实配对集的可下载文件或逐张调焦值。
