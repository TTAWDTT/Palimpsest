# 拍屏不等于强莫尔纹：Dragotti 几何与衍射的条件性预算

2026-09-25。**核心计算：**在 Dragotti 的 Canon EOS600D 配对上，如果原图等比铺满 1080 行显示画幅、发布 PNG 只裁切未缩放，[配对单应估计](真实拍屏跨相机配对与过程约束_2026-09-24.md)给屏幕一格约 **1.32715 个相机图像像素**。格点基频因此约 **0.75349 周期/相机像素**，高于传感器采样 Nyquist 0.5。若没有光学预滤波，一维采样会把它折到约 **0.24651 周期/像素**，即约 **4.06 像素**的伪周期。但作者采用的小光圈恰可能在采样前抑制这一格点。以下是**理论敏感性分析**，不是在发布 PNG 中测得的镜头 MTF 或真实曝光。

## 公式和输入口径

对理想、无像差、单色、非相干成像圆孔，像面光学 MTF 截止频率是 `1/(λN)` 周期/长度；用相机像素间距 `p` 换算为 `fc=p/(λN)` 周期/像素。[亚利桑那大学光学课程](https://wp.optics.arizona.edu/jcwyant/wp-content/uploads/sites/13/2016/08/6Diffraction.pdf)给出这个截止式，[Edmund Optics 的圆孔 MTF 说明](https://www.edmundoptics.com/knowledge-center/application-notes/optics/introduction-to-modulation-transfer-function/)给出 `MTF=2/π·[arccos(r)−r√(1−r²)]`，其中 `r=f/fc`，`r≥1` 时理想 MTF 为零。这里 `p=4.30652 µm` 取自 [Dragotti/Thongkamwitoon 论文的 EOS600D 设计示例](https://www.commsp.ee.ic.ac.uk/~pld/publications/IEEETransactionsINFS_THT_HM_PLD15.pdf)；蓝/绿/红的 **460/540/610 nm** 是示意单色波段，**不是显示器实测光谱**。

[作者博士论文的参数核查](Dragotti公开采集参数与物理约束_2026-09-24.md)显示 EOS600D **f/11** 出现在文字设计示例，**f/13** 出现在相机级设置表，发布 PNG 没有逐张 EXIF。下面把两者都列为条件情形。另加 **f/8** 仅作未来实验对照，**不是**这批图的采集设置。

| 假设光圈 | 蓝 460 nm：格点处理想 MTF | 绿 540 nm | 红 610 nm |
|---|---:|---:|---:|
| f/8，假想干预 | 0.241 | 0.139 | 0.066 |
| f/11，作者设计示例 | **0.046** | **0** | **0** |
| f/13，作者表格 | **0** | **0** | **0** |

绿色格点基频落到理想衍射截止外的临界光圈约 **f/10.58**；红色约 **f/9.37**；蓝色约 **f/12.42**。所以 f/11 示例下，绿红格点的理想光学传递为零、蓝色仅约 4.6%；f/13 表格情形下，三个示意波段的格点基频都落在截止外。色彩子像素更高的空间谐波一般更易被该理想低通压制。这一量级与作者刻意选择距离和较小光圈以减少**可见**混叠的说明相容，不能反过来证明某张发布图完全没有屏幕残余或确认其真实光圈。

## 为什么只能作条件性约束

1. **格点尺度不是直接测量。**1.32715 来自原 JPG→发布再拍 PNG 的单应换算，依赖“显示内容等比填满 1080 行、输出未再缩放”。实际逐像素显示帧、未裁切相机图及逐张处理记录未发布。若有额外缩放，则上述周期/相机**传感器**像素的解释失效。
2. **光学截止是理想模型。**标称光圈不必等于有限距离成像的有效像面 f 数；实际显示光谱连续、镜头像差/离焦、像素面积积分、Bayer CFA、去马赛克、锐化和发布处理都会改变可见条纹。f/11 与 f/13 在作者材料中并存，不能任选其一当逐张真值。
3. **不能从“看不到莫尔纹”判定没拍屏。**该设计在物理上允许屏幕格点被采样前低通大幅压低。另一台设备、距离、角度、光圈或对焦可以把格点重新带进光学通带，条纹也可能随相位与 CFA 改变。模拟器因此应按投影尺度、波长/光圈、采样相位联动生成**强、弱以及无明显可见条纹**的结果，而不是固定叠一层周期纹理。

我还用已经 CRC/SHA 核过的三个场景、EOS600D 与 D3200 共六对图，做了一个**探索性**频谱负对照：每对取 8 个源图配准后较平滑的 256 方块，在按条件性格距折叠得到的频段上，比较再拍图与配准原拍图的窄带功率/邻频功率比。EOS600D 三场景的再拍/原拍比值分别为 **4.20/4.24、6.14/4.53、4.47/3.88**；D3200 为 **7.48/3.80、5.82/4.10、5.75/3.91**。它们既不全为零，也没有跨场景一致的单一窄峰强度。该固定轴向频带忽略了局部旋转、透视与 CFA/ISP，原拍对照又经过 JPEG 和重采样，**不能据此认定**发布 PNG 的屏幕格点确实被衍射完全滤掉，或把某个峰归因为莫尔纹。逐块结果与程序在 `work/dragotti_predicted_alias_spectrum.json`、`experiments/dragotti/probe_dragotti_predicted_alias_spectrum.py`。这次负对照的作用是阻止把上述理想预算直接写成实测结果。

这份预算为后续模拟给出一个可证伪干预：在固定屏幕/相机相对位置、补偿曝光变化且保留原生图的条件下，比较 f/8、f/11、f/13 附近的屏幕格点残余和内容锐度。真实设备暂无条件采集，因此**尚未**据此估计本项目模拟器的显示填充率或镜头 PSF。用户当前无法提供手机拍摄；这不阻止利用公开数据继续验证其他链段。

数值脚本与输入审计分别是 `experiments/dragotti/check_dragotti_diffraction_alias_budget.py`、`work/dragotti_diffraction_alias_budget.json` 及[Dragotti 配对审计](Dragotti跨设备配对审计_2026-09-24.json)。在仓库根目录复算：

```powershell
uv run python -m experiments.dragotti.check_dragotti_diffraction_alias_budget
uv run python -m experiments.dragotti.probe_dragotti_predicted_alias_spectrum
```
