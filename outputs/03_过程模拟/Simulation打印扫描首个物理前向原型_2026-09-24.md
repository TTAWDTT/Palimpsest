# 打印扫描 simulation：单色物理链原型与真实网点的首轮反证

2026-09-24。**状态：有物理坐标与正确环节顺序的可运行结构原型；尚未标定真实打印机、纸张或扫描器。**前置真实档案核验见[DFD 数据与网点审计](打印扫描真实数据与网点参数审计_2026-09-24.md)。这一步有意只做灰度打印—平板扫描，不把色彩打印、拍打印件或 RR 的四类混合再数字化假装成一条链。

## 实现了什么

`origin_simulation/print_scan.py` 接收已知灰度数字图及其预期物理像素密度（digital PPI），按英寸坐标依序计算：

`数字灰阶 → 打印转移曲线 → 有方向/周期的 RIP 网点 → 可选机械网点扩张和沉积模糊 → 墨/纸反射率与纸张散射 → 扫描光学低通和像素孔径近似 → 扫描采样/旋转 → 扫描噪声与输出曲线`。

网点目前是**有序方形点函数**；纸张与扫描器各用 Gaussian PSF；扫描像素孔径用等二阶矩 Gaussian 近似。它们是能替换、能单独干预的结构假设，不是 DFD 任一设备的真实 RIP 程序、纸张 PSF 或扫描器 MTF。`screen_lpi` 用物理单位线/英寸，扫描 PPI 决定最终离散图中的频率；打印机网点形成在扫描取样**之前**。程序保存网点掩模、纸面反射率、扫描前反射率、线性扫描及输出图，以便以后用真实测量检查各级。

四项机制测试与原有测试合计 **25 项通过**：纯白/纯黑给出预期纸/墨反射率；同一 100 线/英寸网点在 800→400 ppi 扫描下，像素域基频从约 0.125→0.25 cycles/px；增大纸张散射抑制网点峰；机械网点扩张使输出变暗。它们只检验代码遵守设定的机制，不是对真实设备的验证。

## 与 DFD 一张真实灰块对照时，暴露出什么缺口

把 D5 的 `DC1_x` 浅灰块 512×512 扫描作为观察对照。为了测试最简模型的上限，直接把真实图的最强峰径向值 **141.42 线/英寸**作为虚拟网点频率输入；输入数字灰度、墨/纸反射率、10 μm 的简化 PSF 都只是示意值。下表为同一 FFT 口径（灰块均值、标准差和指定峰/邻近频带中位数），**没有用 DFD 数字源逐像素标定**：

| 条件 | 均值（0–1） | 标准差 | 峰/频带中位数 |
|---|---:|---:|---:|
| D5 真实扫描灰块 | 0.699 | 0.144 | 318 |
| 虚拟规则网点，10 μm 扫描模糊，零噪声 | 0.689 | 0.269 | 约 3.2×10⁹* |
| 同上，加 0.028 线性噪声代理 | 0.689 | 0.270 | 1766 |
| 噪声代理固定，扫描模糊 30 μm | 0.689 | 0.156 | 1081 |
| 噪声代理固定，扫描模糊 55 μm | 0.689 | 0.049 | 294 |

\*零噪声的理想周期模型使背景频带接近数值零，巨大的比值本身不是可比较的物理量。0.028 噪声仅取自该扫描的空白纸区域标准差量级；空白纸还有纸纹、照明和扫描器贡献，**不能把 0.028 说成扫描器读出噪声真值**。

这个限定参数扫描下，30 μm 模糊能把标准差拉近，却仍留下过强的相干周期峰；55 μm 能把峰比拉近，却把灰块对比度抹得过低。**这只能说明当前规则点阵+单一模糊/白噪声假设未同时解释这两项观察值**，不能推出缺口一定来自哪一个物理环节，也不是全参数最优化结果。真实网点形变、沉积分布、纸纹、扫描器 MTF、未知数字灰度/曲线都可能参与；需要有已知数字测试图、重复印张和受控扫描，才能把这些贡献拆开。这正是过程模拟要接受的反证，而不是为了生成“像扫描图”的噪声随意补一个残差。

可复算：`uv run python -m work.compare_dfd_print_scan_prototype`；逐项数据写入 `work/dfd_print_scan_prototype_comparison.json`。频谱参数来源与完整档案 SHA 见前一篇审计。该比较使用**同一张真实灰块来选频率并观察差异**，所以不能作为留出集或对外性能数字。

## 下一步的实验门槛

1. 把 DFD 里可确认的同图样、同扫描 PPI、同打印设置分组；用不同灰阶块估计**配置级网点向量**而不是仅取单块最高峰，并检验另一台同型号打印机。峰可能是谐波，须结合各阶峰和空间点阵确定基本周期。没有数字 P3/P8 文件时，只能约束网点与末端统计，不能拟合完整 `x→y` 传递。
2. 利用 DESCAN 的原图/真实扫描配对检查输出端的颜色、边缘与纹理，但先审计源页重复、配准影响与扫描器划分。有效外推应以**未见扫描器与未见页面**报告，不能把同页相邻 1024 裁切当独立样本。
3. 若后续能拿到已知数字灰阶测试图、真正同纸不同 DPI/方向的扫描、重复印张和扫描器原始设置，才逐项标定转移、点阵、纸散射与扫描器 PSF。即使在单设备上拟合成功，也需未见设置/设备的检验。现在不据这个虚拟原型训练最终来源模型。

打印扫描原型与[拍屏原型](Simulation第二阶段_透视时间链与可运行渲染_2026-09-24.md)是两条独立物理链；RRDataset 的无逐图方式标签混合集不能代替两条链各自的真实设备验证。
