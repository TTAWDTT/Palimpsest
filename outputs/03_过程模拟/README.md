# 过程模拟：当前研究主线

**最新打印扫描证据：**[DFD 完整档案与网点条件审计](打印扫描真实数据与网点参数审计_2026-09-24.md)核实 114 张真实扫描页实际混有 53 张 800 ppi TIFF、58 张约/确认为 600 ppi 的 TIFF/PNG，另 3 张 PNG 未编码 DPI；七组同型号双设备的灰块网点峰随配置变化，空白纸为阴性对照。[首个灰度前向原型](Simulation打印扫描首个物理前向原型_2026-09-24.md)已能按打印网点→纸面→扫描光学/采样运行，却在真实灰块上暴露了规则点阵过度相干的缺口，尚未完成真实设备标定。

**当前进展：**[拍屏前向模拟第二阶段](Simulation第二阶段_透视时间链与可运行渲染_2026-09-24.md)已支持透视、可选 PWM/逐行曝光、分块渲染、单图 CLI，以及把棋盘实测二维几何接入渲染器的坐标桥。含屏幕子像素、光学低通、Bayer/RAW 噪声与简化 ISP。21 项内部测试通过，包括投影尺度改变时格点混叠频率的预测、光学低通抑制混叠；尚无真实设备校准。[首版空间链](Simulation首个物理前向原型_拍屏空间链_2026-09-24.md)保留研发轨迹。

**最新真实配对审计：**[Dragotti 八相机同源再拍与第二原拍复核](真实拍屏跨相机配对与过程约束_2026-09-24.md)从官方 ZIP 按 Range 抽取、逐图 CRC/SHA 核验 12 个再拍条目；其几何关系稳定，且该数据刻意抑制可见莫尔纹。图像来自同一场景，没有逐张距离/光圈/RAW，不能视为已经完成物理标定。[机器可读记录](Dragotti跨设备配对审计_2026-09-24.json)。

**跨场景新增结果：**[下一阶段路线与 Dragotti 复核](下一阶段路线与Dragotti跨场景复核_2026-09-24.md)又核验室外水池、博物馆两个不同场景中的四张对应再拍，EOS600D/D3200 的条件性几何换算仍稳定；这支持发布流程的几何一致性，不等于已恢复真实屏幕像素或镜头参数。[机器可读复核](Dragotti跨场景几何复核_2026-09-24.json)。

**采集参数校正：**[Dragotti 博士论文设置表核查](Dragotti公开采集参数与物理约束_2026-09-24.md)找到了八台再拍相机的标称距离、焦距、光圈，同时发现 Canon 600D 的 f/11 文字示例与 f/13 表格不一致。它们不是发布 PNG 的逐张元数据。

**首轮采集物料：**[校准包与实验准备](受控拍屏校准物料与首轮实验准备_2026-09-24.md)说明已生成的 E 盘 17 张图案、哈希清单与会话核验工具；[操作单](../../docs/controlled_screen_capture_runbook.md)列拍摄顺序和字段。尚无本机真实拍屏照片。
