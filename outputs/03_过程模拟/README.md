# 过程模拟：当前研究主线

**当前进展：**已实现[拍屏空间链前向原型](Simulation首个物理前向原型_拍屏空间链_2026-09-24.md)，含屏幕子像素、投影、光学低通、Bayer/RAW 噪声和简化 ISP；仅通过内部结构测试，尚无真实设备校准。

**最新真实配对审计：**[Dragotti 八相机同源再拍与第二原拍复核](真实拍屏跨相机配对与过程约束_2026-09-24.md)从官方 ZIP 按 Range 抽取、逐图 CRC/SHA 核验 12 个再拍条目；其几何关系稳定，且该数据刻意抑制可见莫尔纹。图像来自同一场景，没有逐张距离/光圈/RAW，不能视为已经完成物理标定。[机器可读记录](Dragotti跨设备配对审计_2026-09-24.json)。

建议按以下顺序阅读：

1. [过程物理深读](Simulation过程物理深读_屏摄与印刷成像_2026-09-24.md)：屏幕发光、几何与光学、CFA/RAW/ISP、打印扫描和投影的因果顺序；哪些参数不可从最终 JPEG 唯一反推。
2. [受控采集准备与数据可用性审计](Simulation受控采集准备与数据可用性审计_2026-09-24.md)：各真实配对集能检验什么、DESCAN 本机元数据抽查、UHDM 下载入口的实际状态。
3. [RR 处理来源与评测协议](RRDataset处理来源核查与Simulation评测协议_2026-09-24.md)：RR 内部来源冻结、发布处理标签的证据边界。

补充推理：[机理与证据缺口](Simulation机理与证据缺口深读_2026-09-24.md)、[物理路径与外部验证矩阵](Simulation物理路径与外部验证矩阵_2026-09-24.md)。早期统计原型的逐阶段记录已归入[历史探索](../90_历史探索/README.md)。

可执行的拍屏条件/元数据设计见项目 `docs/controlled_screen_capture_protocol.md`。**当前没有已经完成物理验证的 simulation。**

2026-09-24 早期阶段的[真实数据可用性审计](Simulation受控采集准备与数据可用性审计_2026-09-24.md)第 7 节先核查 Dragotti ZIP 目录：1,440 个再拍文件名可关联到原拍名称；当时还未抽取图像。其后第 8 节抽取首个配对，本页顶部所链最新报告继续扩展到 12 个再拍条目；**整包仍未下载或全量验图**。CLEAR/MIRAGE 作者页目前将数据下载标为 “Coming Soon”。

同日报告第 8 节继续核验了一组实际图像：CRC 与视觉配对通过；同时校正公开 ZIP 对应论文的**评测划分**（900 原拍、1,440 再拍），不是论文所述全采集库。再拍样本 PNG 缺相机 EXIF，物理控制量仍需自行采集或另寻元数据。

同日[受控数据再检索](真实拍屏受控数据再检索_2026-09-24.md)找到 DeepMoiréFake 的真实拍屏条件元数据（需申请、约 199 GiB）以及 VD_raw 的真实拍屏 RAW/sRGB 入口；分别能补视角/设备分组与 RAW→ISP 子链检验，但尚无已核实的公开逐图“距离×角度×对焦×曝光”完整干预网格。
